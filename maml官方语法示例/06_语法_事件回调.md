# 事件回调

> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-trigger.html

---

## 按钮事件回调

Button 元素可以接收点击、按下、双击、移动等事件（小部件只支持点击与按下事件）。

| 属性 | 释义 |
|------|------|
| `x, y, w, h` | 指定坐标、区域大小 |
| `alignChildren` | true/false，默认 false。true 时内部元素按绝对坐标排布，false 时按相对坐标 |
| `interceptTouch` | 是否截获后续触摸事件，防止被其他 View 捕获（如防止桌面滚动） |
| `Normal` | 正常状态，包含的元素只在此状态下显示 |
| `Pressed` | 按下状态，包含的元素只在此状态下显示 |

Trigger action 值：

| action | 说明 |
|--------|------|
| `down` | 按下 |
| `up` | 抬起（点击） |
| `double` | 双击 |
| `move` | 移动 |
| `cancel` | 滑出 |

```xml
<Button x="" y="" w="" h="" interceptTouch="true">
    <Triggers>
        <Trigger action="down">
            <VariableCommand name="test1" expression="0" />
        </Trigger>
        <Trigger action="up">
            <VariableCommand name="test2" expression="0" />
        </Trigger>
        <Trigger action="double">
            <VariableCommand name="test3" expression="0" />
        </Trigger>
    </Triggers>
    <Normal>
        <Image/>
        <Text/>
    </Normal>
    <Pressed>
        <Image/>
        <Text/>
    </Pressed>
</Button>
```

普通绘图元素也能被点击，只需添加 `touchable` 属性：

```xml
<Image src="icon.png" x="0" y="0" w="100" h="100" touchable="true">
    <Triggers>
        <Trigger action="up">
            <VariableCommand name="clicked" expression="1"/>
        </Trigger>
    </Triggers>
</Image>
```

## 布局同时存在全局点击和局部点击

需要在主标签 Widget 设置 `version="2"`，并且将除全局外的 Button 设置 `interception="true"`：

```xml
<Widget version="2" screenWidth="1080">
    <!-- 全局按钮 -->
    <Button x="0" y="0" w="#screen_width" h="#screen_height">
        <Triggers>
            <Trigger action="up">
                <!-- 全局点击逻辑 -->
            </Trigger>
        </Triggers>
    </Button>
    <!-- 局部按钮，需要设置 interception="true" -->
    <Button x="100" y="100" w="200" h="200" interception="true">
        <Triggers>
            <Trigger action="up">
                <!-- 局部点击逻辑 -->
            </Trigger>
        </Triggers>
    </Button>
</Widget>
```

## 动画回调

动画完成时触发回调事件：

```xml
<Var name="ani">
    <VariableAnimation loop="false" initPause="true">
        <AniFrame value="0" time="0"/>
        <AniFrame value="1" time="500"/>
        <Triggers>
            <Trigger action="end">
                <!-- 动画完成后执行 -->
                <VariableCommand name="animDone" expression="1"/>
            </Trigger>
        </Triggers>
    </VariableAnimation>
</Var>
```

## 阈值回调

变量状态变化时触发回调，当变量变化量大于阈值时触发：

```xml
<!-- 每秒触发一次（#second 每秒变化1） -->
<Var name="second_trigger" expression="#second">
    <Triggers>
        <Trigger threshold="1">
            <!-- 每秒执行一次 -->
            <VariableCommand name="count" expression="#count+1"/>
        </Trigger>
    </Triggers>
</Var>
```

> 注意：阈值触发的原理是两次刷新之间变量的值变化大于阈值。如果当前帧率为0，变量不会被刷新，也就不会触发事件回调。

## 生命周期回调

maml 提供三个生命周期回调：`init`、`pause`、`resume`。

```xml
<Widget version="2" screenWidth="1080" frameRate="0" useVariableUpdater="DateTime.Minute">
    <ExternalCommands>
        <!-- maml 首次加载时触发 -->
        <Trigger action="init">
            <VariableCommand name="str" expression="'我已经init了'" type="string"/>
        </Trigger>
        <!-- 离开 maml 应用时触发（跳转到其他应用，或划出 maml 所在屏幕） -->
        <Trigger action="pause">
            <VariableCommand name="str" expression="'离开了'" type="string"/>
        </Trigger>
        <!-- 返回 maml 应用时触发 -->
        <Trigger action="resume">
            <VariableCommand name="str" expression="'我又回来了'" type="string"/>
        </Trigger>
    </ExternalCommands>
</Widget>
```

> 注意：maml 的 xml 文件里最多只能放置一个 `ExternalCommands` 标签。`ExternalCommands` 还可用于 maml 与宿主应用（如桌面）进行通信，宿主应用发送自定义 action 可触发对应回调。

## 广播回调

maml 可以接受其他应用发送的全局广播并触发回调：

```xml
<VariableBinders>
    <BroadcastBinder action="BROADCAST_ACTION_NAME">
        <!-- 接收广播数据，绑定到 num 变量，extra="value" 为广播发来的参数名 -->
        <Variable name="num" type="number" extra="value" />
        <Trigger>
            <!-- 接收到广播后的回调，可添加对应命令 -->
        </Trigger>
    </BroadcastBinder>
</VariableBinders>
<Text x="500" y="360" color="#ff00ff" size="50" textExp="#num" />
```
