# 动画控制

> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-animation.html

---

## 差值器属性动画

### 定义动画

用一个特殊的 number 类型变量来定义动画：

```xml
<Var name="ani">
    <VariableAnimation loop="false" initPause="true">
        <AniFrame value="100" time="0" easeType="SineEaseOut"/>
        <AniFrame value="500" time="500"/>
    </VariableAnimation>
</Var>

<Rectangle name="rect" x="#ani" y="100" w="100" h="100" fillColor="#ff0000"/>

<Button x="0" y="0" w="#screen_width" h="#screen_height">
    <Triggers>
        <Trigger action="up">
            <AnimationCommand target="ani" command="play"/>
        </Trigger>
    </Triggers>
</Button>
```

点击按钮后，`ani` 变量从 100 过渡到 500，矩形 x 坐标随之移动。

差值器动画可以设置不同的缓动曲线效果，详见：https://zhuti.designer.xiaomi.com/docs/grammar/#缓动函数

### 控制动画播放区间

```xml
<!-- 按下时从0ms播放到300ms，松手时从300ms播放到600ms -->
<Button x="0" y="0" w="#screen_width" h="#screen_height">
    <Triggers>
        <Trigger action="down">
            <AnimationCommand target="ani" command="play(0,300)"/>
        </Trigger>
        <Trigger action="up">
            <AnimationCommand target="ani" command="play(300,600)"/>
        </Trigger>
    </Triggers>
</Button>
```

### 动画控制命令

| 命令 | 释义 |
|------|------|
| `play` | 播放/继续播放动画 |
| `play(from,to)` | 指定开始时间和结束时间播放 |
| `pause` | 暂停动画 |
| `resume` | 从头开始播放 |

## 序列帧动画

通过 `srcid` 属性绑定变量控制当前渲染哪一帧：

```xml
<Var name="frameIndex" expression="0"/>
<Image src="xiongben.png" srcid="#frameIndex" x="0" y="0" w="200" h="200"/>
```

> 序列帧图片命名方式：`前缀_n.png`，如 `xiongben_0.png`、`xiongben_1.png`...
> 使用时只需传入前缀 `xiongben.png`，maml 自动匹配对应帧。

序列帧动画也可以通过命令控制播放：

```xml
<Button x="0" y="0" w="#screen_width" h="#screen_height">
    <Triggers>
        <Trigger action="down">
            <AnimationCommand target="frameIndex" command="play(0,500)"/>
        </Trigger>
        <Trigger action="up">
            <!-- 从500ms反向播放到0ms -->
            <AnimationCommand target="frameIndex" command="play(500,0)"/>
        </Trigger>
    </Triggers>
</Button>
```

## Folme 动画

maml 支持通过 Folme 来控制动画，适合弹性、物理感动画。

### FolmeState（状态定义）

预先定义元素需要到达的状态：

```xml
<FolmeState name="stateA" x="100" y="200" w="300" h="300" rotation="45" alpha="255" />
```

支持的基本属性：

| 名称 | 说明 | 备注 |
|------|------|------|
| `name` | 必填，状态名 | String |
| `x` | x 坐标 | number 表达式 |
| `y` | y 坐标 | number 表达式 |
| `w` | 宽度 | number 表达式 |
| `h` | 高度 | number 表达式 |
| `rotation` | 旋转角度 | number 表达式 |
| `rotationX/Y/Z` | 各轴旋转角度 | number 表达式 |
| `alpha` | 透明度 | 0~255 |
| `scaleX/Y` | 各轴缩放比例 | number 表达式 |
| `pivotX/Y/Z` | 旋转中心点 | number 表达式 |
| `tintColor` | 染色颜色 | 16进制数字，如 0xffffffff |

特殊属性（特定元素独有）：

| 名称 | 说明 |
|------|------|
| `r` | 圆的半径（圆形独有） |
| `textSize` | 文字大小（文字独有） |
| `textColor` | 文字颜色（文字独有，number 类型） |
| `textShadowColor` | 文字阴影颜色 |
| `fillColor` | 填充颜色（几何独有，number 类型） |
| `strokeColor` | 描边颜色（几何独有，number 类型） |
| `cornerRadiusX/Y` | 矩形圆角（圆角矩形独有） |
| `strokeWeight` | 描边宽度（几何图形独有） |

### FolmeConfig（动画曲线配置）

```xml
<FolmeConfig name="configA" delay="0" ease="-2, 0.5, 0.9">
    <!-- Special 用于定制某个特殊属性的动画曲线 -->
    <Special property="'x'" delay="100" ease="1"/>
</FolmeConfig>
```

| 名称 | 说明 |
|------|------|
| `name` | 名称 |
| `property` | FolmeState 中属性的名字，如 `property="'x'"` 或 `property="'x','y'"` |
| `delay` | 延时（ms） |
| `ease` | 曲线类型，第一个参数为曲线类型编号，后续为参数 |
| `fromSpeed` | 初始速度 |
| `onBegin` | 动画开始时的回调函数名 |
| `onUpdate` | 动画进行中的回调函数名 |
| `onComplete` | 动画完成时的回调函数名 |

曲线类型编号：

```java
int REBOUND = -6;    // 反弹，参数：回弹速度比(0~1)
int STOP = -5;
int FRICTION = -4;   // 摩擦，参数：dragFriction(0~1)
int ACCELERATE = -3; // 加速，参数：加速度(Kpixels/s^2)
int SPRING_PHY = -2; // 物理弹簧，参数：damping, response
int DURATION = -1;   // 指定时长，参数：duration(ms)
// 时间插值器
int SPRING = 0;      // 弹簧，参数：damp, response
int LINEAR = 1;      // 线性
int QUAD_IN = 2;     int QUAD_OUT = 3;     int QUAD_INOUT = 4;
int CUBIC_IN = 5;    int CUBIC_OUT = 6;    int CUBIC_INOUT = 7;
int QUART_IN = 8;    int QUART_OUT = 9;    int QUART_INOUT = 10;
int QUINT_IN = 11;   int QUINT_OUT = 12;   int QUINT_INOUT = 13;
int SIN_IN = 14;     int SIN_OUT = 15;     int SIN_INOUT = 16;
int EXPO_IN = 17;    int EXPO_OUT = 18;    int EXPO_INOUT = 19;
```

### Folme 动画控制命令

```xml
<!-- 将元素从当前状态运动到状态A，支持打断 -->
<FolmeCommand target="test" command="to" states="'stateA'" config="'configA'" />

<!-- 将元素从当前状态直接变为状态A（无动画） -->
<FolmeCommand target="test" command="setTo" states="'stateA'" />

<!-- 将元素从状态A运动到状态B -->
<FolmeCommand target="test" command="fromTo" states="'stateA', 'stateB'" config="'configA'"/>

<!-- 结束当前动画 -->
<FolmeCommand target="test" command="cancel" />

<!-- 结束当前动画的部分属性 -->
<FolmeCommand target="test" command="cancel" params="'x', 'y'"/>
```
