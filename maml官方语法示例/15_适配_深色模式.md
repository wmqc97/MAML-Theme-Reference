# 适配深色模式

> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-dark.html

---

## 全局变量

```
#__darkmode                 是否开启深色模式：0未开启，1已开启
#__darkmode_wallpaper       是否开启深色模式且支持调暗壁纸：0未开启，1已开启
#applied_light_wallpaper    壁纸主色调：0深色，1浅色
```

---

## 基于深色模式切换颜色

```xml
<Widget version="2" screenWidth="1080" frameRate="0">
    <!-- 深色模式下显示白色文字，浅色模式下显示黑色文字 -->
    <Text x="#view_width/2" y="#view_height/2"
        color="ifelse(#__darkmode==1,'#ffffff','#000000')"
        size="50"
        textExp="'Hello'"
        align="center"/>

    <!-- 深色模式下显示深色背景图，浅色模式下显示浅色背景图 -->
    <Image src="ifelse(#__darkmode==1,'bg_dark.png','bg_light.png')"
        x="0" y="0" w="#view_width" h="#view_height"/>
</Widget>
```

---

## 基于壁纸颜色适配

有时需要根据用户添加的壁纸自动适配深色或浅色模式：

```xml
<!-- 壁纸为深色时（applied_light_wallpaper=0），文字用白色；壁纸为浅色时，文字用黑色 -->
<Text x="100" y="100"
    color="ifelse(#applied_light_wallpaper==0,'#ffffff','#000000')"
    size="50"
    textExp="@content"/>
```

## 深色模式预览图

适配深色模式后，预览图也需要添加深色模式的预览图。若当前小部件无深色模式效果，可复制一份浅色模式的预览图并加后缀 `_dark`：

```
preview/
├── widget_4x2.png           # 浅色模式预览图
├── widget_4x2_dark.png      # 深色模式预览图
├── widget_4x2_zh_CN.png     # 中文浅色预览图
└── widget_4x2_zh_CN_dark.png # 中文深色预览图
```

## 深浅色切换强制刷新

因为 maml 仅在桌面划到当前小部件所在块时触发 resume 进行重新渲染，切换深浅色模式时会有较大的观感差异。可以添加以下代码，在深浅色切换时立即刷新小部件：

```xml
<VariableBinders>
    <BroadcastBinder action="android.intent.action.CONFIGURATION_CHANGED">
        <Trigger>
            <MethodCommand target="__objRoot" targetType="var" method="selfResume" />
        </Trigger>
    </BroadcastBinder>
</VariableBinders>
```
