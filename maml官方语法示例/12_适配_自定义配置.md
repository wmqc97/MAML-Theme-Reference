# 小部件自定义配置

> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-config.html

通过在 `manifest.xml` 的同级目录下添加 `var_config.xml` 实现小部件的自定义功能。每一项必须配置 `name` 属性，`name` 对应 `manifest.xml` 中用到的变量。

---

## 自定义文本（支持多个）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<WidgetConfig version="1" des="说明-可变的变量修改">
    <Text name="textContent" displayTitle="显示内容" editable="true" minLength="4" maxLength="8">
        <item>小米科技</item>
        <item>今天吃什么</item>
        <item>今天喝水了吗</item>
    </Text>
</WidgetConfig>
```

| 字段名 | 说明 |
|--------|------|
| `name` | 必填，对应 manifest.xml 中的变量名 |
| `displayTitle` | 小标题文案，默认「显示内容」 |
| `editable` | 是否可输入，false/true |
| `maxLength` | 最长支持字符数 |
| `minLength` | 最短支持字符数 |
| `item` | 默认内容，最多支持100条 |

---

## 自定义颜色（支持多个）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<WidgetConfig version="1" des="说明-可变的变量修改">
    <Color name="textColor" displayTitle="字体颜色">
        <item>#000000</item>
        <item>#ff0000</item>
        <item>#ffff00</item>
        <item>#00ff00</item>
        <item>#0088ff</item>
    </Color>
</WidgetConfig>
```

| 字段名 | 说明 |
|--------|------|
| `name` | 必填，对应 manifest.xml 中的变量名 |
| `displayTitle` | 小标题文案，默认「字体颜色」 |
| `item` | 6位颜色值，默认使用第一个，最多支持30种颜色 |

---

## 自定义颜色组（支持一个）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<WidgetConfig version="1" des="说明-可变的变量修改">
    <ColorGroup name="colorStyle" displayTitle="配色样式" uiType="0">
        <Var name="color1" values="#000FF0,#ff0000,#ffff00,#00ff00,#0088ff" />
        <Var name="color2" values="#111111,#dddddd,#333333,#eeeeee,#555555" />
        <Var name="color3" values="#000099,#009900,#118822,#229922,#ff0088" />
    </ColorGroup>
</WidgetConfig>
```

| 字段名 | 说明 |
|--------|------|
| `name` | 必填，对应 manifest.xml 中的变量名 |
| `displayTitle` | 小标题文案，默认「配色样式」 |
| `uiType` | 0=默认，1=双色 |
| 默认选择 | 首套，即 color1取第一个值，color2取第一个值...最多支持30种选择 |

---

## 滑动条（支持多个）

可用来调节透明度、字体大小等，支持配置最大值、最小值、默认值：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<WidgetConfig version="1" des="说明-可变的变量修改">
    <FontSize name="textSize" default="120" from="80" to="160" displayTitle="范围调节"/>
</WidgetConfig>
```

| 字段名 | 说明 |
|--------|------|
| `name` | 必填，对应 manifest.xml 中的变量名 |
| `displayTitle` | 小标题文案，默认「范围调节」 |
| `default` | 默认值（int） |
| `from` / `to` | 调节范围 |

---

## 自定义对齐方式（支持一个）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<WidgetConfig version="1" des="说明-可变的变量修改">
    <Align name="alignMent" default="0" from="0" to="5" displayTitle="文字排版" />
</WidgetConfig>
```

| 值 | 说明 |
|----|------|
| 0 | 横排左对齐 |
| 1 | 横排居中 |
| 2 | 横排右对齐 |
| 3 | 竖排左对齐 |
| 4 | 竖排居中 |
| 5 | 竖排右对齐 |

---

## 自定义样式 - 图片位（支持多个）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<WidgetConfig version="1" des="说明-可变的变量修改">
    <ImageSelect name="image1" displayTitle="选择图片" height="152" width="286" uiType="0">
        <item displayTitle="图片1">image/a1.png</item>
        <item displayTitle="图片2">image/a2.png</item>
        <item displayTitle="图片3">image/a3.png</item>
    </ImageSelect>
</WidgetConfig>
```

| 字段名 | 说明 |
|--------|------|
| `name` | 必填，对应 manifest.xml 中的变量名 |
| `displayTitle` | 小标题文案，默认「选择图片」 |
| `width` / `height` | 必填，素材图尺寸，支持八种尺寸 |
| `uiType` | 0=默认，1=当前页(每行2列)，10=跳转新页(每行2列)，20=跳转新页(每行3列) |
| `item` | 必填，图片在资源包中的路径，至少2个 |

支持的八种尺寸（宽×高）：286×152、266×152、451×152、286×286、246×246、286×346、250×306、184×246

## 设定时间（支持一个）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<WidgetConfig version="1" des="说明-可变的变量修改">
    <!-- default 不写时默认当前系统时间，repeat 是重复类型 -->
    <SetDate name="dateAA" default="2023-10-01" repeat="0" repeatVar="repeatAA" />
</WidgetConfig>
```

| 字段名 | 说明 |
|--------|------|
| `name` | 必填，对应 manifest.xml 中的变量名 |
| `default` | 格式「2021-07-13」，缺省值为当前系统日期 |
| `repeat` | 0=不重复（默认），1=每年，2=每月，3=每周 |
| `repeatVar` | manifest 中使用的变量名 |

日期差值计算函数 `diffDate(目标日期ms, 当前日期ms, 重复类型)`，返回距离目标日期的差值（单位：天）。

> 注意：所有属性在 manifest.xml 中都需要设置默认值，时间的默认值需要是毫秒时间戳形式，例如 2023-10-01 对应 1696089600000。

## 开关（支持多个）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<WidgetConfig version="1" des="说明-可变的变量修改">
    <!-- 默认1，到 manifest.xml 中 1表示on，0表示off -->
    <OnOff name="state1" default="1" displayTitle="状态控制"/>
</WidgetConfig>
```

| 字段名 | 说明 |
|--------|------|
| `name` | 必填，对应 manifest.xml 中的变量名 |
| `default` | 开关状态，0或1，默认开（1） |
| `displayTitle` | 小标题文案，默认「状态控制」 |
