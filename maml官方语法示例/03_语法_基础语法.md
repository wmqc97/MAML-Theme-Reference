# 基础语法

> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-grammar.html

## 数据类型

maml 的数据类型分为两大类：**基础数据类型**、**元素对象**。

基础数据类型包括：数字类型、字符串类型及对应的数组类型。

---

## 变量声明

```xml
<!-- 数字类型变量 -->
<Var name="a" expression="200" />
<Var name="b" expression="#a + 100" type="number"/>
<Var name="c" expression="2" type="int"/>
<Var name="d" expression="2.56" type="float"/>

<!-- 字符串类型变量 -->
<Var name="e" expression="'永远相信美好的事情即将发生'" type="string"/>

<!-- 数组 -->
<Var name="f" values="100,200,300,400" type="number[]"/>
<Var name="g" values="'hello','world'" type="string[]"/>

<!-- 固定长度数组（const） -->
<Var name="h" size="3" const="true" type="number[]"/>
<Var name="h" expression="40" type="number[]" index="0" const="true"/>
<Var name="h" expression="50" type="number[]" index="1" const="true"/>
<Var name="h" expression="60" type="number[]" index="2" const="true"/>
```

---

## 变量引用

- 数字类型用 `#变量名`
- 字符串类型用 `@变量名`
- 数组元素用 `#变量名[索引]` 或 `@变量名[索引]`

```xml
<Text x="100" y="100" color="#ffffff" size="50" textExp="#num"/>
<Text x="100" y="200" color="#ffffff" size="50" textExp="@str"/>
<Text x="100" y="300" color="#ffffff" size="50" textExp="#numArr[1]"/>
<Text x="100" y="400" color="#ffffff" size="50" textExp="@strArr[1]"/>
```

## 变量修改

通过 `VariableCommand` 命令修改变量，**必须放在 Trigger 中触发**：

```xml
<Var name="a" expression="200" const="true" />
<Var name="b" values="100,200,300,400" type="number[]" const="true"/>

<Button x="0" y="0" w="#screen_width" h="#screen_height">
    <Triggers>
        <Trigger action="up">
            <VariableCommand name="a" expression="300"/>
            <VariableCommand name="b" expression="500" index="1" type="number[]"/>
        </Trigger>
    </Triggers>
</Button>
```

## 运算符

| 操作符 | 优先级 | 释义 |
|--------|--------|------|
| `+` | 4 | 加 |
| `-` | 4 | 减 |
| `*` | 3 | 乘以 |
| `/` | 3 | 除以 |
| `%` | 3 | 取模 |
| `^` | 10 | 按位异或 |
| `~` | 2 | 按位取反 |
| `{{` | 5 | 左移位 |
| `}}` | 5 | 右移位 |
| `!` | 2 | 逻辑非 |
| `==` | 7 | 等于 |
| `!=` | 7 | 不等于 |
| `**` | 11 | 逻辑与（相当于 &&） |
| `\|\|` | 12 | 逻辑或 |
| `}` | 6 | 大于（相当于 >） |
| `}=` | 6 | 大于等于（相当于 >=） |
| `{` | 6 | 小于（相当于 <） |
| `{=` | 6 | 小于等于（相当于 <=） |

## 内置方法

**数学函数**：`sin`、`cos`、`tan`、`asin`、`acos`、`atan`、`sinh`、`cosh`、`sqrt`、`abs`、`min`、`max`、`pow`

| 方法 | 说明 |
|------|------|
| `len(数字)` | 获取变量和字符串位数 |
| `digit(数字, 第几位)` | 取给定数字的第几位，如 `digit(12345, 2) = 4`（下标从右向左，从1开始，原数字不超过10位） |
| `substr(原字符串, 开始位置, 长度)` | 截取子串，如 `substr('今天真热啊',1,2) = '天真'`（位置从0开始） |
| `strIsEmpty(字符串变量)` | 判断字符串是否为空，空返回1，非空返回0 |
| `isnull(数字型变量)` | 判断变量是否为空，空返回1，非空返回0 |
| `ceil()` | 向上取整 |
| `int()` | 向下取整 |
| `round()` | 四舍五入取整 |
| `rand()` | 取0到1之间的随机数 |
| `formatDate('HH:mm', #time_sys)` | 日期格式化成字符串 |
| `strStartsWith('123456789','12')` | 判断字符串是否以某字符串开头，是返回1 |
| `eqs(@str,'a')` | 比较两个字符串是否相等，是返回1 |
| `strEndsWith('123456789','89')` | 判断字符串是否以某字符串结束，是返回1 |
| `strIndexOf(@string_a,'string_b')` | 字符串 b 第一次出现在 a 中的位置 |
| `strLastIndexOf(@string_a,'string_b')` | 字符串 b 最后出现在 a 中的位置 |
| `strContains(@string_a,'string_b')` | 字符串 a 是否包含 b，包含返回1 |
| `strReplaceAll(@string_a,'string_b','string_c')` | 用 c 替换 a 中所有的 b，支持正则 |
| `preciseeval('@string_a', 3)` | 计算字符串的值并精确到小数点后3位 |
| `formatFloat('%.3f', #accx)` | 格式化小数点后几位并转换成字符串（会占位，如3.000） |
| `strMatches(@str,'.*[\+*/-]$')` | 正则表达式匹配 |
| `strTrim(' 123 ')` | 裁切字符串开头和尾部的空格、制表、回车符 |
| `strReplaceFirst('ABCdefABC','ABC','666')` | 替换第一个匹配项 |
| `strToLowerCase('ABCdef')` | 转换成小写 |
| `strToUpperCase('ABCdef')` | 转换成大写 |
