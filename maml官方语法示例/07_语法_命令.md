# 命令（Command）

> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-command.html

所有命令作为 Command 的一种，**必须放在 Trigger 或 Function 函数体内部**来执行调用。

---

## 变量命令（VariableCommand）

设置变量值：

```xml
<Trigger>
    <VariableCommand name="a" expression="#a+1"/>
</Trigger>
```

详见：[变量的修改](./03_语法_基础语法.md#变量修改)

---

## 动画命令（AnimationCommand）

控制动画的播放：

```xml
<Trigger>
    <AnimationCommand target="ani" command="play"/>
</Trigger>
```

详见：[控制动画](./05_语法_动画控制.md#动画控制命令)

---

## Intent 命令（IntentCommand）

maml 可以调用安卓的 Intent 类主动发送消息给本地安卓应用，或唤起一个应用。

### 打开应用（通过包名/类名）

```xml
<IntentCommand action="android.intent.action.MAIN"
    package="com.android.thememanager"
    class="com.android.thememanager.ThemeResourceTabActivity" />
```

### 通过 deeplink 打开快应用

```xml
<IntentCommand uri="com.miui.hybrid://hybrid.xiaomi.com/app/com.yidian.hybrid.main" />
```

### 打开一个 URL

```xml
<IntentCommand action="android.intent.action.VIEW"
    package="com.android.browser"
    class="com.android.browser.BrowserActivity"
    uriExp="'www.mi.com'"/>
```

### 设置日历提醒

```xml
<IntentCommand action="android.intent.action.VIEW"
    uriExp="'http://calendar.miui.com/event/insert?title=xxx&amp;startTimeMillis=1477390112074&amp;endTimeMillis=1477390312074&amp;url=http%3A%2F%2Fwww.xiaomi.com&amp;urlText=跳转按钮文案'"/>
```

### 发送广播

```xml
<!-- 不带参数发送广播 -->
<IntentCommand action="BROADCAST_ACTION_NAME" broadcast="true"/>

<!-- 带参数发送广播 -->
<IntentCommand action="BROADCAST_ACTION_NAME" broadcast="true">
    <Extra name="sendValueName" type="number" expression="1000" />
</IntentCommand>

<!-- 通过包名指定接收方 -->
<IntentCommand action="BROADCAST_ACTION_NAME" broadcast="true" package="com.miui.home">
    <Extra name="sendValueName" type="number" expression="1000" />
</IntentCommand>
```

## 刷新 Provide 接口数据（BinderCommand）

```xml
<Trigger>
    <BinderCommand name="binderName" command="refresh" />
</Trigger>
```

---

## 帧率命令（FrameRateCommand）

动态控制小部件帧率，用于节省功耗：

```xml
<!-- 提高帧率（播放动画时） -->
<FrameRateCommand rate="120" />

<!-- 降低帧率（动画结束后） -->
<FrameRateCommand rate="0" />
```

---

## 方法调用命令（FunctionCommand）

调用已定义的 Function：

```xml
<FunctionCommand target="myFun" />
```

---

## Folme 动画命令（FolmeCommand）

```xml
<FolmeCommand target="elementName" command="to" states="'stateA'" config="'configA'" />
<FolmeCommand target="elementName" command="setTo" states="'stateA'" />
<FolmeCommand target="elementName" command="fromTo" states="'stateA', 'stateB'" config="'configA'"/>
<FolmeCommand target="elementName" command="cancel" />
```

---

## Graphics 绘图命令（GraphicsCommand）

```xml
<GraphicsCommand target="canvasName" command="setRenderListener" paramsExp="'drawFunctionName'"/>
<GraphicsCommand target="canvasName" command="lineStyle" colors="#FFFFFFFF" paramsExp="4"/>
<GraphicsCommand target="canvasName" command="moveTo" paramsExp="100,100"/>
<GraphicsCommand target="canvasName" command="lineTo" paramsExp="400,400"/>
```

详见：[画布 Graphics](./11_语法_画布Graphics.md)

---

## 反射命令（MethodCommand / FieldCommand）

通过反射调用安卓原生方法：

```xml
<MethodCommand targetType="var" target="__objRoot" method="selfResume" />
<FieldCommand targetType="var" target="__objContext" class="com.miui.maml.ScreenContext"
    return="thisContext" field="mContext" returnType="object" method="get"/>
```
