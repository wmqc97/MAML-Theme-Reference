# 绘图元素

> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-draw.html

maml 绘图元素的属性都是基于表达式来计算，通过绑定变量进行绘图。`Group` 组里面的绘图元素会自动继承 group 的坐标，内部坐标均基于 group 的原点进行计算（坐标均基于像素计算）。

---

## 图片（Image）

### 基本图片

```xml
<Image src="图片路径.png" x="0" y="0" w="100" h="100" />
```

详细属性参考：https://zhuti.designer.xiaomi.com/docs/grammar/#图片

### 时间图片（TimeImage）

时间图片继承自图片，用于快速用图片方式实现格式化时间效果。

素材命名规则：`前缀_0.png`、`前缀_1.png`...`前缀_9.png`，冒号图片命名为 `前缀_dot.png`。使用时只需写前缀，maml 自动拼接。

```xml
<TimeImage src="time.png" x="0" y="0" format="HH:mm" />
```

### 数字图片（NumberImage）

数字图片继承自图片，只需准备 0~9 的十张图片（命名规则同时间图片）。

```xml
<NumberImage src="num.png" x="0" y="0" numExp="#battery_level" />
```

## 元素数组（Array）

让界面元素以特定规律的形式展现，避免重复代码。

```xml
<!-- 绘制 10 个 60x60 的矩形顺序排列 -->
<Array count="10" indexName="i">
    <Rectangle x="#i * 70" y="0" w="60" h="60" fillColor="#ff0000" />
</Array>
```

| 属性 | 释义 |
|------|------|
| `Array` | 元素数组标签，对各元素进行排列 |
| `indexName` | 索引名称，可理解为给各元素编号的变量名 |
| `count` | 元素数组内同类型元素的个数（不支持表达式） |

Array 标签同时继承 Group，内部元素的坐标、旋转、透明度及是否显示等属性同样受 Array 标签影响。

---

## Group 组

```xml
<Group x="100" y="100" visibility="#show">
    <Image src="icon.png" x="0" y="0" w="50" h="50" />
    <Text x="60" y="10" color="#ffffff" size="30" textExp="@label" />
</Group>
```

- 内部元素坐标基于 Group 原点计算
- `visibility` 属性控制整组显示/隐藏（0隐藏，1显示）
