## 快速搜索规则

**AI 读取流程**：
1. 先读取本索引文件（约 2KB）
2. 根据用户意图匹配关键词
3. 只读取命中的 1~3 个目标文件
4. 不要一次性读取所有文件

**示例**：
- 用户问"怎么写 OnOff 开关" → 匹配 `配置规范/11-var-config-配置项完整示例.md`（2.1 OnOff）
- 用户问"AOD 状态下怎么隐藏动画" → 匹配 `实战技巧/05-AOD与省电实践.md`（三重保险）
- 用户问"怎么获取电池电量" → 匹配 `进阶主题/10-日程与电池信息获取.md`（电池广播）
- 用户问"胶囊充电动画怎么写" → 匹配 `基础语法/02-UI元素与动画.md`（第三节）
- 用户问"HTML 怎么封装进主题" / "WebView 加载网页" → 匹配 `实战技巧/12-WebView加载HTML到背屏.md`（已验证）
- 用户问"帮我写个 HTML 背屏时钟/科技感主题" → 匹配 `实战技巧/13-HTML背屏主题完整示例-星舰矩阵时钟.md`（完整样板，照抄改）
- 用户问"主题名称/作者写在哪" / "var_config 还能写标题吗" → 匹配 `配置规范/06-var-config与description-xml.md`（只写 description.xml）
- 用户问"expression 变量被覆盖怎么办" → 匹配 `实战技巧/07-踩坑记录.md`（坑1）
- 用户说"创建/优化背屏 Web 主题"（HTML 加载型）→ 匹配 `实战技巧/14-背屏Web主题-AI创作规范.md`（总纲：默认约定/避让/手势/流程，先读）+ `实战技巧/13-HTML背屏主题完整示例-星舰矩阵时钟.md`（照抄模板）
