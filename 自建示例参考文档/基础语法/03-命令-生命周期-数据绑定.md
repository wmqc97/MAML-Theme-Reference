## 一、命令汇总

所有命令必须放在 `Trigger` 标签内。

| 命令 | 用途 |
|------|------|
| `VariableCommand` | 设置变量值 |
| `AnimationCommand` | 控制动画播放/暂停 |
| `FrameRateCommand` | 设置帧率（0=停止渲染） |
| `FunctionCommand` | 调用函数 |
| `BinderCommand` | 刷新数据绑定 |
| `IntentCommand` | 打开应用/URL/发送广播 |
| `ExternCommand` | 系统开关（蓝牙/WiFi/解锁等） |
| `SoundCommand` | 播放音效 |
| `Command` | 控制元素可见性 |
| `IfCommand` | 条件分支 |
| `SensorCommand` | 开关传感器 |
| `FolmeCommand` | 关键帧动画控制 |

### 常用示例

```xml
<VariableCommand name="aodState" expression="0" type="number"/>
<FrameRateCommand rate="60"/>
<FrameRateCommand rate="0"/>
<BinderCommand name="getData" command="refresh"/>
<FunctionCommand target="updateAll"/>

<!-- 打开应用 -->
<IntentCommand action="android.intent.action.MAIN"
    package="com.android.thememanager"
    class="com.android.thememanager.ThemeResourceTabActivity"/>

<!-- 发送广播 -->
<IntentCommand action="BROADCAST_ACTION" broadcast="true">
    <Extra name="key" type="number" expression="1000"/>
</IntentCommand>

<!-- 系统开关 -->
<ExternCommand command="bluetooth" numPara="state,ifelse(#bluetooth_state==1,0,1)"/>
<ExternCommand command="wifi" numPara="state,ifelse(#wifi_state==1,0,1)"/>

<!-- 可见性 -->
<Command target="elementName" property="visibility" value="true"/>
<Command target="elementName" property="visibility" value="toggle"/>

<!-- 条件分支 -->
<IfCommand ifCondition="(#a==1)">
    <Consequent>...</Consequent>
    <Alternate>...</Alternate>
</IfCommand>
```

## 二、生命周期事件（ExternalCommands）

背屏宿主（MamlView）发送命令，主题用 `Trigger action="..."` 响应：

| 事件 | 触发时机 | 典型操作 |
|------|---------|---------|
| `init` | 组件加载 | 初始化变量、启动动画、刷新数据、设置帧率60 |
| `enterAod` | 进入 AOD | 停动画、帧率→0、隐藏流光 |
| `exitAod` | 退出 AOD | 恢复动画、帧率→60、显示流光 |
| `pause` | 可见性丢失 | 停动画、帧率→0 |
| `resume` | 恢复可见 | 恢复动画、刷新数据 |
| `notification_received` | 收到通知 | 显示通知动画 |

```xml
<ExternalCommands>
    <Trigger action="init">
        <VariableCommand name="aodState" expression="1" type="number"/>
        <BinderCommand name="getData" command="refresh"/>
        <FunctionCommand target="updateAll"/>
        <AnimationCommand target="anim" command="play"/>
        <FrameRateCommand rate="60"/>
    </Trigger>
    <Trigger action="enterAod">
        <VariableCommand name="aodState" expression="0" type="number"/>
        <AnimationCommand target="anim" command="pause"/>
        <FrameRateCommand rate="0"/>
    </Trigger>
    <Trigger action="exitAod">
        <VariableCommand name="aodState" expression="1" type="number"/>
        <AnimationCommand target="anim" command="play"/>
        <FrameRateCommand rate="60"/>
    </Trigger>
</ExternalCommands>
```

## 三、数据绑定（VariableBinders）

### 广播绑定（BroadcastBinder）

```xml
<BroadcastBinder action="android.intent.action.BATTERY_CHANGED">
    <Variable name="batteryLevel" type="int" extra="level"/>
    <Variable name="batteryPlugType" type="int" extra="plugged"/>
    <Variable name="batteryTemp" type="int" extra="temperature"/>
    <Variable name="batteryVolt" type="int" extra="voltage"/>
    <Variable name="batteryTech" type="string" extra="technology"/>
    <Variable name="batteryHealth" type="int" extra="health"/>
    <Trigger><FunctionCommand target="update"/></Trigger>
</BroadcastBinder>
```

### ContentProvider 绑定

```xml
<ContentProviderBinder name="getData" uri="content://..." columns="a,b" countName="hasData">
    <Variable name="_a" type="long" column="a"/>
    <Trigger><FunctionCommand target="parse"/></Trigger>
</ContentProviderBinder>
```

### UriRoute 绑定（权限版）

```xml
<ContentProviderBinder name="getData" uriExp="@DATA_URI" columns="code,result">
    <Variable name="result_json" column="result" type="string"/>
    <Trigger><FunctionCommand target="parseResult"/></Trigger>
</ContentProviderBinder>
```

### 传感器绑定

```xml
<SensorBinder name="sensor" rate="0" threshold="0.05" type="gyroscope">
    <Variable name="gyro_x" index="0"/>
    <Variable name="gyro_y" index="1"/>
    <Variable name="gyro_z" index="2"/>
    <Trigger><FunctionCommand target="process"/></Trigger>
</SensorBinder>
```

### 常用系统数据源

| 数据源 | URI |
|------|------|
| 存储空间 | `content://com.miui.securitycenter.widgetProvider/getCleanMasterData` |
| 内存 | `content://com.miui.securitycenter.widgetProvider/getMemoryData` |
| 步数 | `content://com.mi.health.provider.main/activity/steps/brief` |
| 电量详情 | `content://com.miui.securitycenter.widgetProvider/getPowerData` |
| 设备信息 | `content://com.miui.personalassistant.deviceinfo` |
| 日历 | `content://com.miui.calendar/transparentevents` |
| UriRoute | `content://uriroute/data?group=wmqc&name=spec` |

## 四、变量阈值触发

```xml
<Var name="ticker" expression="#second" threshold="1">
    <Trigger><FunctionCommand target="checkTick"/></Trigger>
</Var>
```
变量变化超过 threshold 时触发命令。

## 五、函数定义与调用

```xml
<Function name="updateAll">
    <VariableCommand name="gradeIndex" expression="ifelse(gt(#batteryLevel,80),1,gt(#batteryLevel,60),2,gt(#batteryLevel,40),3,gt(#batteryLevel,20),4,5)" type="number"/>
    <VariableCommand name="needRefresh" expression="0" type="number"/>
</Function>

<!-- 调用 -->
<FunctionCommand target="updateAll"/>
```
