## 一、UI 元素速查

### 常用 UI 元素一览

| 元素 | 关键属性 |
|------|---------|
| `Rectangle` | x,y,w,h,fillColor,strokeColor,cornerRadiusExp,rotation,alpha,visibility |
| `Text` | x,y,size,fontPath,fontPathWeight,textExp,color,align,alignV,visibility |
| `Arc` | x,y,w,h,startAngle,sweep,strokeColor,weight,cap,close |
| `Line` | x,y,x1,y1,strokeColor,weight,cap |
| `Group` | x,y,visibility（子元素容器） |

所有坐标/尺寸均可写表达式，如 `(116 * #s)`。

---

### Image（图片）

```xml
<Image src="a.png" x="0" y="0" w="100" h="100" alpha="255"
       srcid="#id" srcExp="'path/'+@folder+'/img.png'"
       rotation="45" pivotX="50" pivotY="50"
       blur="5" antiAlias="true" visibility="#show"
       cornerRadius="20" tint="#ff0000" scale="#s"/>
```

- `srcid`：自动追加后缀，`src="a.png" srcid="3"` → `a_3.png`
- `srcExp`：支持表达式，如 `srcExp="('frames/'+floor((#time%10000)/40)+'.png')"`

### NumberImage（数字图片映射）

```xml
<NumberImage src="num.png" number="#battery_level" x="0" y="0" space="2"/>
```
需准备 `num_0.png`~`num_9.png`

### TimeImage（时间图片）

```xml
<TimeImage src="time.png" format="HH:mm" x="0" y="0" space="2"/>
```
需准备 `time_0.png`~`time_9.png` 和 `time_dot.png`

---

### Rectangle（矩形）

```xml
<Rectangle x="0" y="0" w="100" h="100"
           fillColor="#FF0000" strokeColor="#000000" weight="2"
           cornerRadiusExp="20*#s" alpha="200" cap="round"
           strokeAlign="center" visibility="#show"/>
```

### Text（文本）

```xml
<Text x="0" y="0" size="40" color="#FFFFFF" textExp="#hour24+':'+#minute"
      fontPath="/system/fonts/MiSansVF.ttf" fontPathWeight="400"
      align="center" alignV="center" alpha="255" visibility="#show"/>
```

- `color`：支持 `#RRGGBB` 或 `#AARRGGBB`
- 特殊字符：`'&#10;'` 换行

### Arc（弧线）

```xml
<Arc x="0" y="0" w="200" h="200"
     startAngle="-90" sweep="90" fillColor="#00000000"
     strokeColor="#FFF" weight="3" cap="round"
     strokeAlign="center" close="false"/>
```
- `startAngle`：起始角度，`-90`=12点方向
- `sweep`：扫过角度

### Line（直线）

```xml
<Line x="0" y="0" x1="100" y1="100" strokeColor="#FFF" weight="2" cap="round"/>
```

### Group（容器）

```xml
<Group x="0" y="0" visibility="#show">
    <!-- 子元素 -->
</Group>
```

### VirtualScreen（虚拟屏幕，用于倒影/遮罩）

```xml
<VirtualScreen name="v" w="500" h="300">
    <Text x="0" y="0" size="100" color="#F0F" textExp="'Hello'"/>
</VirtualScreen>
<Image src="v" useVirtualScreen="true"/>
<!-- 倒影：翻转+模糊 -->
<Image src="v" useVirtualScreen="true" blur="20" rotationX="180" alpha="100"/>
```

## 二、动画系统

### 变量动画（VariableAnimation）

```xml
<Var name="ani" type="number" expression="0">
    <VariableAnimation initPause="true" loop="true">
        <AniFrame value="0" time="0" easeType="SineEaseOut"/>
        <AniFrame value="360" time="2000"/>
    </VariableAnimation>
</Var>
```

- `initPause="true"`：默认暂停，手动 play
- `loop="true"`：循环播放
- `time`：绝对时间(ms)；`dtime`：相对时间
- `easeType`：`SineEaseOut`/`BackEaseIn(1.5)`/`ElasticEase(2,3)` 等

### 元素动画（PositionAnimation/AlphaAnimation 等）

```xml
<Image src="ball.png" x="0" y="0" w="100" h="100">
    <PositionAnimation loop="true">
        <PosFrame x="0" time="0"/>
        <PosFrame x="#screen_width" time="1000"/>
    </PositionAnimation>
    <AlphaAnimation loop="true">
        <AlphaFrame alpha="255" time="0"/>
        <AlphaFrame alpha="0" time="1000"/>
    </AlphaAnimation>
</Image>
```

### 关键帧动画（Folme，MIUI13+）

```xml
<FolmeState name="stateA" x="100" y="200" alpha="255"/>
<FolmeState name="stateB" x="500" y="200" alpha="128"/>
<FolmeConfig name="configA" ease="-2, 0.5, 0.9"/>
<Rectangle name="test" x="100" y="200" w="100" h="100" fillColor="#f00" folmeMode="true"/>
<!-- 触发 -->
<FolmeCommand target="test" command="to" states="'stateB'" config="'configA'"/>
```

### 动画控制命令

```xml
<AnimationCommand target="ani" command="play"/>          <!-- 从头播放 -->
<AnimationCommand target="ani" command="play(0,500)"/>   <!-- 播放0~500ms -->
<AnimationCommand target="ani" command="pause"/>          <!-- 暂停 -->
<AnimationCommand target="ani" command="resume"/>         <!-- 继续 -->
```

### 触发器（Trigger on variable）

```xml
<Var name="autoRefresh" expression="#second" threshold="1">
    <Trigger><FunctionCommand target="checkTick"/></Trigger>
</Var>
```
变量变化超过 threshold 时触发命令。

## 三、充电动画实战（完整案例）

以下为「能效标识」主题电量胶囊充电流光动画的完整实现。

### Step 1：机型判断 + 胶囊尺寸

```xml
<!-- Pro Max（长屏）：宽高比 > 1.6；Pro：其余 -->
<Var name="isProMax" type="number" expression="ifelse(gt(#view_width/#view_height,1.6),1,0)"/>
<Var name="isPro" type="number" expression="(1 - #isProMax)"/>
<Var name="_scale" type="number" expression="(#view_width / 1080)"/>
<Var name="x_left" type="number" expression="ifelse(#isProMax,320,350)*#_scale"/>
<Var name="capW" type="number" expression="(#x_left / #scale - 2)"/>
<Var name="capH" type="number" expression="(#view_height / #scale - 2 - 5 / #scale)"/>
<Var name="capR" type="number" expression="(#capW / 2)"/>
<!-- 电量环颜色：随电量阈值变化 -->
<Var name="ringColor" type="string" expression="ifelse(le(#batteryLevel,15),'#FF4444',le(#batteryLevel,30),'#FF8C00',le(#batteryLevel,60),'#FFD54F','#4CAF50')"/>
```

### Step 2：充电流光动画驱动

```xml
<Var name="chargeAnim" type="number" expression="0">
  <VariableAnimation initPause="true" loop="true">
    <Item value="0" time="0"/>
    <Item value="360" time="2000"/>
  </VariableAnimation>
</Var>
<!-- 胶囊周长分段（圆角矩形：2 半圆 + 2 直线） -->
<Var name="seg1" type="number" expression="(3.14159 * #capR / 2)"/>
<Var name="segL" type="number" expression="(#capH - #capW)"/>
<Var name="seg3" type="number" expression="(3.14159 * #capR)"/>
<Var name="e1" type="number" expression="#seg1"/>
<Var name="e2" type="number" expression="(#e1 + #segL)"/>
<Var name="e3" type="number" expression="(#e2 + #seg3)"/>
<Var name="e4" type="number" expression="(#e3 + #segL)"/>
<Var name="capPerim" type="number" expression="(#e4 + #seg1)"/>
<Var name="capPathT" type="number" expression="max(0,min(#capPerim,#capPerim*#batteryLevel/100))"/>
<!-- 流光可见性：三重保险 -->
<Var name="chargeFlowVisible" type="number"
     expression="ifelse(eqs(@aod_desk_state,'1'), 0,
                 ifelse(#aodState == 0, 0,
                 ifelse(#batteryPlugType } 0, 1, 0)))"/>
<!-- 流光位置 -->
<Var name="chargePos" type="number" expression="(#chargeAnim / 360 * #capPerim)"/>
<Var name="chargeTrailLen" type="number" expression="max(18,#capPerim * 0.18)"/>
<Var name="chargeTail" type="number" expression="(#chargePos - #chargeTrailLen)"/>
<Var name="dashA0" type="number" expression="max(0,#chargeTail)"/>
<Var name="dashA1" type="number" expression="#chargePos"/>
<Var name="dashB0" type="number" expression="ifelse(lt(#chargeTail,0),#chargeTail + #capPerim,#capPerim)"/>
<Var name="dashB1" type="number" expression="#capPerim"/>
```

### Step 3：胶囊渲染（底框 + 电量环 + 流光 + 文字）

```xml
<Group x="(#scale + 2)" y="(#scale + 4)" visibility="(#showCapsule_v == 1)">
  <!-- 底框 -->
  <Rectangle x="0" y="0" w="(#capW * #scale)" h="(#capH * #scale)"
              fillColor="#00000000" strokeColor="#2E4E63" weight="(2 * #scale)"
              cap="round" strokeAlign="center" cornerRadiusExp="#capR*#scale" alpha="153"/>
  <!-- 电量环（5 段：上弧 → 右线 → 下弧 → 左线 → 上弧尾） -->
  <Arc visibility="gt(#capPathT,0)" x="(#capR * #scale)" y="(#capR * #scale)" w="(#capW * #scale)" h="(#capW * #scale)"
       fillColor="#00000000" strokeColor="@ringColor" weight="(2 * #scale)" cap="round"
       strokeAlign="center" close="false" startAngle="-90"
       sweep="90*min(#seg1,max(0,#capPathT))/#seg1" alpha="#breathAlpha"/>
  <Line visibility="gt(#capPathT,#e1)" x="(#capW * #scale)" y="(#capR * #scale)"
        x1="(#capW * #scale)" y1="((#capR+min(#segL,max(0,#capPathT-#e1)))*#scale)"
        strokeColor="@ringColor" weight="(2 * #scale)" cap="round" strokeAlign="center" alpha="#breathAlpha"/>
  <Arc visibility="gt(#capPathT,#e2)" x="(#capR * #scale)" y="((#capH - #capR) * #scale)" w="(#capW * #scale)" h="(#capW * #scale)"
       fillColor="#00000000" strokeColor="@ringColor" weight="(2 * #scale)" cap="round"
       strokeAlign="center" close="false" startAngle="0"
       sweep="180*min(#seg3,max(0,#capPathT-#e2))/#seg3" alpha="#breathAlpha"/>
  <Line visibility="gt(#capPathT,#e3)" x="0" y="((#capH - #capR) * #scale)"
        x1="0" y1="((#capH-#capR-min(#segL,max(0,#capPathT-#e3)))*#scale)"
        strokeColor="@ringColor" weight="(2 * #scale)" cap="round" strokeAlign="center" alpha="#breathAlpha"/>
  <Arc visibility="gt(#capPathT,#e4)" x="(#capR * #scale)" y="(#capR * #scale)" w="(#capW * #scale)" h="(#capW * #scale)"
       fillColor="#00000000" strokeColor="@ringColor" weight="(2 * #scale)" cap="round"
       strokeAlign="center" close="false" startAngle="180"
       sweep="90*min(#seg1,max(0,#capPathT-#e4))/#seg1" alpha="#breathAlpha"/>

  <!-- 充电流光（A 段 + B 段跨零点） -->
  <Group visibility="#chargeFlowVisible">
    <!-- A 段（头→尾，正方向） -->
    <Arc visibility="gt(min(#e1,#dashA1)-max(0,#dashA0),0)" x="(#capR*#scale)" y="(#capR*#scale)" w="(#capW*#scale)" h="(#capW*#scale)"
         fillColor="#00000000" strokeColor="#FFFFFF" weight="(3*#scale)" cap="butt" strokeAlign="center" close="false"
         startAngle="(-90 + 90 * max(0,#dashA0) / #seg1)"
         sweep="(90 * max(0,min(#e1,#dashA1)-max(0,#dashA0)) / #seg1)" alpha="220"/>
    <Line visibility="gt(min(#e2,#dashA1)-max(#e1,#dashA0),0)" x="(#capW*#scale)" y="((#capR + max(#e1,#dashA0) - #e1)*#scale)"
          x1="(#capW*#scale)" y1="((#capR + min(#e2,#dashA1) - #e1)*#scale)"
          strokeColor="#FFFFFF" weight="(3*#scale)" cap="butt" strokeAlign="center" alpha="220"/>
    <Arc visibility="gt(min(#e3,#dashA1)-max(#e2,#dashA0),0)" x="(#capR*#scale)" y="((#capH-#capR)*#scale)" w="(#capW*#scale)" h="(#capW*#scale)"
         fillColor="#00000000" strokeColor="#FFFFFF" weight="(3*#scale)" cap="butt" strokeAlign="center" close="false"
         startAngle="(180 * (max(#e2,#dashA0) - #e2) / #seg3)"
         sweep="(180 * max(0,min(#e3,#dashA1)-max(#e2,#dashA0)) / #seg3)" alpha="220"/>
    <Line visibility="gt(min(#e4,#dashA1)-max(#e3,#dashA0),0)" x="0" y="((#capH - #capR - (max(#e3,#dashA0) - #e3))*#scale)"
          x1="0" y1="((#capH - #capR - (min(#e4,#dashA1) - #e3))*#scale)"
          strokeColor="#FFFFFF" weight="(3*#scale)" cap="butt" strokeAlign="center" alpha="220"/>
    <Arc visibility="gt(min(#capPerim,#dashA1)-max(#e4,#dashA0),0)" x="(#capR*#scale)" y="(#capR*#scale)" w="(#capW*#scale)" h="(#capW*#scale)"
         fillColor="#00000000" strokeColor="#FFFFFF" weight="(3*#scale)" cap="butt" strokeAlign="center" close="false"
         startAngle="(180 + 90 * (max(#e4,#dashA0) - #e4) / #seg1)"
         sweep="(90 * max(0,min(#capPerim,#dashA1)-max(#e4,#dashA0)) / #seg1)" alpha="220"/>
    <!-- B 段（尾跨越 0 点，回绕到周长末端） -->
    <Arc visibility="gt(min(#e1,#dashB1)-max(0,#dashB0),0)" x="(#capR*#scale)" y="(#capR*#scale)" w="(#capW*#scale)" h="(#capW*#scale)"
         fillColor="#00000000" strokeColor="#FFFFFF" weight="(3*#scale)" cap="butt" strokeAlign="center" close="false"
         startAngle="(-90 + 90 * max(0,#dashB0) / #seg1)"
         sweep="(90 * max(0,min(#e1,#dashB1)-max(0,#dashB0)) / #seg1)" alpha="220"/>
    <Line visibility="gt(min(#e2,#dashB1)-max(#e1,#dashB0),0)" x="(#capW*#scale)" y="((#capR + max(#e1,#dashB0) - #e1)*#scale)"
          x1="(#capW*#scale)" y1="((#capR + min(#e2,#dashB1) - #e1)*#scale)"
          strokeColor="#FFFFFF" weight="(3*#scale)" cap="butt" strokeAlign="center" alpha="220"/>
    <Arc visibility="gt(min(#e3,#dashB1)-max(#e2,#dashB0),0)" x="(#capR*#scale)" y="((#capH-#capR)*#scale)" w="(#capW*#scale)" h="(#capW*#scale)"
         fillColor="#00000000" strokeColor="#FFFFFF" weight="(3*#scale)" cap="butt" strokeAlign="center" close="false"
         startAngle="(180 * (max(#e2,#dashB0) - #e2) / #seg3)"
         sweep="(180 * max(0,min(#e3,#dashB1)-max(#e2,#dashB0)) / #seg3)" alpha="220"/>
    <Line visibility="gt(min(#e4,#dashB1)-max(#e3,#dashB0),0)" x="0" y="((#capH - #capR - (max(#e3,#dashB0) - #e3))*#scale)"
          x1="0" y1="((#capH - #capR - (min(#e4,#dashB1) - #e3))*#scale)"
          strokeColor="#FFFFFF" weight="(3*#scale)" cap="butt" strokeAlign="center" alpha="220"/>
    <Arc visibility="gt(min(#capPerim,#dashB1)-max(#e4,#dashB0),0)" x="(#capR*#scale)" y="(#capR*#scale)" w="(#capW*#scale)" h="(#capW*#scale)"
         fillColor="#00000000" strokeColor="#FFFFFF" weight="(3*#scale)" cap="butt" strokeAlign="center" close="false"
         startAngle="(180 + 90 * (max(#e4,#dashB0) - #e4) / #seg1)"
         sweep="(90 * max(0,min(#capPerim,#dashB1)-max(#e4,#dashB0)) / #seg1)" alpha="220"/>
  </Group>

  <!-- 电量文字 -->
  <Text visibility="#isProMax" x="(#capX_center)" y="(#capH / 2 * #scale)"
        size="(10 * #scale)" fontPath="@font_path"
        textExp="(ifelse(gt(#batteryPlugType,0),'⚡','') + #batteryLevel + '%')"
        fontPathWeight="600" color="@ringColor" align="center" alignV="center"/>
</Group>
```

### Step 4：动画开关事件（AOD 停动画省电）

```xml
<Function name="updateChargeAnim">
  <IfCommand ifCondition="((#batteryPlugType } 0) * (#aodState == 1))">
    <Consequent>
      <AnimationCommand target="chargeAnim" command="play"/>
      <FrameRateCommand rate="60"/>
    </Consequent>
    <Alternate>
      <AnimationCommand target="chargeAnim" command="pause"/>
      <VariableCommand name="chargeAnim" expression="0" type="number"/>
      <FrameRateCommand rate="0"/>
    </Alternate>
  </IfCommand>
</Function>
```

### 实现原理小结

1. **周长分段**：圆角矩形 = 2 半圆弧（seg1、seg3）+ 2 直线（segL），总周长 capPerim
2. **进度绘制**：capPathT = 周长 × 电量%，拆 5 段分别用 Arc/Line 绘制
3. **流光**：动画 0→360 映射到周长位置，白色高亮弧线沿周长流动，A/B 两段处理跨越 0 点回绕
4. **机型**：宽高比 >1.6 = Pro Max（居中单行文字）；否则 Pro（左右分列）
