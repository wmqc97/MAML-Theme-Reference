## 一、机型适配：双基准比例差值法

不要用单一阈值判断，而是用**两个基准屏幕的比例差值**，判断当前屏幕更接近哪个：

```xml
<Var name="q200Width" expression="904" type="number"/>
<Var name="q200Height" expression="572" type="number"/>
<Var name="q200ScreenRatio" expression="(#q200Width/#q200Height)" type="number"/>
<Var name="p2Width" expression="976" type="number"/>
<Var name="p2Height" expression="596" type="number"/>
<Var name="p2ScreenRatio" expression="(#p2Width/#p2Height)" type="number"/>
<Var name="realScreenRatio" expression="(#view_width/#view_height)" type="number"/>
<Var name="diffWithQ200" expression="abs((#realScreenRatio-#q200ScreenRatio))" type="number"/>
<Var name="diffWithP2" expression="abs((#realScreenRatio-#p2ScreenRatio))" type="number"/>
<Var name="isQ200" expression="lt(#diffWithQ200,#diffWithP2)" type="number"/>
<Var name="scale" expression="ifelse(#isQ200,(#view_width/336),((#view_width/364)*1.047))" type="number"/>
```

### 简单版（宽高比阈值）

```xml
<!-- 宽高比 > 1.6 为 Pro Max 类 -->
<Var name="isP2" type="number" expression="ifelse(((#view_width/#view_height)}1.6),1,0)"/>
<Var name="_scale" type="number" expression="(#view_width/1080)"/>
```

## 二、左侧安全区（摄像头避让）

核心原则：**左侧洞区不摆可读内容，仅铺底色占位。**

### 深渊类（isP2 + x_left）

```xml
<Var name="x_left" type="number" expression="ifelse(#isP2,320,350)*#_scale"/>
<Var name="_rect_w" type="number" expression="#view_width-#x_left-100*#_scale"/>
```
- `x_left`：左侧安全区左缘像素宽度
- 主内容从 `x="#x_left"` 起算

### 日历小部件类（更精细的网格对齐）

```xml
<Var name="isQ200" type="number" expression="lt(#diffWithQ200,#diffWithP2)" />
<Var name="scale" type="number" expression="ifelse(#isQ200,(#view_width/336),((#view_width/364)*1.047))" />
<Var name="safe_left" type="number" expression="(120*#scale)-(6*#scale)" />
<Var name="safe_right" type="number" expression="20" />
<Var name="space_w" expression="(33*#scale)" type="number" />
<Var name="grid_col0" expression="(120*#scale)" type="number" />
<Var name="safe_zone_w" expression="int(#grid_col0-#space_w/2)" type="number" />
<Var name="content_center_x" expression="max(#safe_zone_w+330*#vwh_s,#safe_zone_w+(#view_width-#safe_zone_w-#safe_right)/2)" type="number" />
```

### 落地规则

```xml
<!-- 左侧不透明底色条（只铺底色，不摆内容） -->
<Rectangle x="0" y="0" w="#safe_zone_w" h="#view_height" fillColor="@bgColor" alpha="255"/>
<!-- 主内容从 safe_zone_w 右侧开始 -->
```

- 星期/日期：`Text` 的 x 为 `#grid_col0+#_i*#space_w`
- 左箭头：`Button x="#safe_zone_w+int(70*#vwh_s)"`
- 右箭头：`Button x="#view_width-#safe_right-70"`
- 打开日历按钮：`Button x="#safe_zone_w"`，`w="#view_width-#safe_zone_w"`

## 三、两类"摄像头"不要混用

| 作用 | 变量 | 说明 |
|------|------|------|
| **布局安全区（2D 避让）** | `x_left` / `safe_zone_w` / `grid_x` 系 | 解决**遮挡**，只铺底色不摆内容 |
| **GL 描边与姿态（3D 装饰）** | `circleTfPosX/Y` / `CameraVectorRotation` | 装饰镜头圈，**不自动等于**挖孔像素矩形 |

做新主题时，先定 2D 安全区，再决定是否在 GL 层加镜头圈。

## 四、背屏圆角与布局参数

### 常用布局变量

```xml
<Var name="timeWidth" const="true" expression="510+2"/>
<Var name="timeHeight" const="true" expression="254+2"/>
<Var name="EyePos" type="float[]" values="0,0,3"/>
<Var name="eye" type="float[]" values="0,0,3.3"/>
<Var name="center" type="float[]" values="0,0,0"/>
<Var name="up" type="float[]" values="0,1,0"/>
```

### 圆角建议

把圆角抽成两层：
- **外层安全圆角**：限制内容边界
- **内层视觉圆角**：shader 里控制雾化/高光/裁边

### 多机型统一适配最少变量集

```text
#view_width / #view_height
q200ScreenRatio / p2ScreenRatio
isQ200
safe_zone_w
grid_col0 / space_w / scale
content_center_x
safe_right
aod_state（GL 主题需）
```
