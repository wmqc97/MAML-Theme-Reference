## 坑 1：带 expression 的变量无法被命令修改（最重要）

`VariableElement.update()` 每帧用 expression 重新求值 → 覆盖 VariableCommand 写入的值。

```
aodState 定义 expression="1" → enterAod 设 0 无效，永远 1
__aodHideCharge 定义 expression="0" → 永远 0
```

**解决**：需要被命令修改的变量不写 expression：

```xml
<Var name="aodState" type="number"/>  <!-- ✅ 可变 -->
```

---

## 坑 2：AOD 判断别只依赖事件变量

- 事件可能因时序问题未生效
- **系统变量 `aod_desk_state` 由背屏直接 putVariableString 写入，永不被表达式覆盖**，用它做兜底最可靠

---

## 坑 3：权限版数据变量注意

- `tickCount` 若定义 `expression="0" const="true"`，定时计数恒 0，改刷新间隔前需先去掉 expression/const
- 变量若 `const="true"`，`parseResult` 无法覆盖，动态数据会失效

---

## 坑 4：环境限制

- Android 无 `zip` 命令 → 用 `/data/local/tmp/build_zip.sh`
- toybox grep 不支持 `\|` → 用 `grep -e a -e b`
- CRLF 行尾 → grep 前 `tr -d '\r'` 或读取时自行处理

---

## 坑 5：ifelse 参数格式

- `ifelse` 支持 **2n+1** 参数（多条件），不是只能 3 个
- 条件用布尔表达式；字符串相等用 `eqs`，数字用 `eq/ne/gt/ge/lt/le`

---

## 坑 6：权限版 `requirements.packages` 必须写 `com.uriroute`

不是 `com.example.uriroute`，否则安装时会提示缺少依赖。

## 坑 7：AOD 白条隐藏修复案例

### 需求
电量胶囊充电动画白条，AOD 状态下隐藏。

### 错误写法（失效原因）
```xml
<Var name="__aodHideCharge" expression="0"/>  <!-- 永远 0 -->
<Var name="chargeFlowVisible" expression="((#batteryPlugType } 0) * (1 - #__aodHideCharge))"/>
```

### 正确写法
```xml
<!-- 可变状态变量（无 expression） -->
<Var name="aodState" type="number"/>

<!-- 三重保险 -->
<Var name="chargeFlowVisible" type="number"
     expression="ifelse(eqs(@aod_desk_state,'1'), 0,
                 ifelse(#aodState == 0, 0,
                 ifelse(#batteryPlugType } 0, 1, 0)))"/>
```

事件侧：
```xml
<Trigger action="enterAod">
  <VariableCommand name="aodState" expression="0" type="number"/>
  <AnimationCommand target="chargeAnim" command="pause"/>
  <VariableCommand name="chargeAnim" expression="0" type="number"/>
  <FrameRateCommand rate="0"/>
</Trigger>
```

## 坑 8：主题开发最佳实践

1. **状态变量 vs 计算变量分离**
   - 计算变量（尺寸/颜色/可见性）→ 用 `expression`
   - 状态变量（aodState/开关）→ 不写 expression，靠事件设置
2. **AOD 判断一律优先用系统 `aod_desk_state`**
3. **动画省电**：AOD/pause 时 `AnimationCommand pause` + `FrameRateCommand rate="0"`，退出恢复
4. **权限版数据获取**：spec.js 用 `uriRoute.shell()` 读 sysfs，`readFirstReadable` 多路径兜底
5. **机型适配**：用宽高比 `#view_width/#view_height > 1.6` 区分 Pro Max / Pro
6. **缩放基准**：以固定宽度（如 336）为设计基准，`s = #view_width/336` 整体缩放
7. **多行文字显示**：sweep 角度/进度变量先算好，再拆成多个 Arc/Line 分段绘制（白条流光即此法）
