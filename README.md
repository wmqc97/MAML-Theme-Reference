# MAML 主题语法参考

小米主题 MAML 语法参考文档，面向背屏主题与锁屏主题开发者。

## 目录结构

```
├── maml官方语法示例/          ← 官方 MAML 语法文档镜像（17 篇官方 + 12 篇 grammar）
├── 自建示例参考文档/           ← 唯梦倾城实战示例（去重、拆分、按分类整理）
│   ├── 00-搜索索引.md          ← AI 入口，关键词→文件直达
│   ├── 基础语法/               ← 变量、UI、命令、动画
│   ├── 实战技巧/               ← 机型适配、AOD 省电、踩坑
│   ├── 进阶主题/               ← GL、摄像头、日程、电池
│   ├── 配置规范/               ← var_config、description.xml
│   └── REARStore_提交参考文档.md
└── README.md
```

## 使用方式

1. **AI 助手**：先读取 `自建示例参考文档/00-搜索索引.md`，按关键词匹配直达目标文件
2. **人工查阅**：按需进入对应文件夹，每个文件独立可读
3. **官方语法**：`maml官方语法示例/` 包含完整 MAML 语法参考
