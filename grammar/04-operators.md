## 运算符

| 运算符 | 优先级 | 说明                 |
| ------ | ------ | -------------------- |
| +      | 4      | 加法                 |
| -      | 4      | 减法                 |
| *      | 3      | 乘法                 |
| /      | 3      | 除法                 |
| %      | 3      | 取模                 |
| ^      | 10     | 按位异或             |
| ~      | 2      | 按位取反             |
| <<     | 5      | 左移                 |
| >>     | 5      | 右移                 |
| !      | 2      | 逻辑非               |
| ==     | 7      | 等于                 |
| !=     | 7      | 不等于               |
| &&     | 11     | 逻辑与（两者都为真） |
| ||     | 12     | 逻辑或（任一为真）   |
| >      | 6      | 大于                 |
| >=     | 6      | 大于等于             |
| <      | 6      | 小于                 |
| <=     | 6      | 小于等于             |

## 旧版条件函数

仍支持的旧版函数：

| 函数          | 说明               |
| ------------- | ------------------ |
| eq(x,y)       | x==y               |
| ne(x,y)       | x!=y               |
| ge(x,y)       | x>=y               |
| gt(x,y)       | x>y                |
| le(x,y)       | x<=y               |
| lt(x,y)       | x<y                |
| not(x)        | 逻辑非             |
| ifelse(x,y,z) | 若 x>0 则 y 否则 z |
| +             | 字符串拼接         |
| eqs(@s1,@s2)  | 字符串比较         |
