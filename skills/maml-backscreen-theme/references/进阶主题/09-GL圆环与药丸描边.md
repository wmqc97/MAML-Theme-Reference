## 一、GL 圆环多层描边（深渊类）

摄像头描边并不是 2D 画线，而是 GL 圆环网格 + 材质厚度 + 多实例偏移叠出来的。

### 1.1 几何体与材质

```xml
<Primitive name="mCirclePrimitive" glb="assets/circle.glb" mod="2"/>
<RenderMaterial name="mCircleMaterial" shader="mCircleShader">
    <Uniform name="uThickness" type="float" value="#circle_thickness_init"/>
</RenderMaterial>
```

### 1.2 描边厚度实时更新

通过 Folme 的 `circle_thickness` 驱动 `uThickness`，AOD 会把它压到 0（等于隐藏描边）：

```xml
<Uniform name="uThickness" type="float" value="#folme_gl.circle_thickness/#_folme_scale"/>
<FolmeState name="folme_gl_aod_state" circle_thickness="#circle_thickness_aod*#_folme_scale"/>
```

### 1.3 多圈描边层次

`mCircleUBO.instanceOffsets` 写入 9 组偏移，形成同心层叠描边：

```xml
<Property name="instanceOffsets" type="float" count="9"
 value="#circleOff*8,#circleOff*7,#circleOff*6,#circleOff*5,#circleOff*4,#circleOff*3,#circleOff*2,#circleOff*1,#circleOff*0"/>
```

### 1.4 跟随摄像头姿态

`CameraVectorRotation` 同步给圆环材质，描边会随设备姿态产生"跟镜头"变化。

### 1.5 圆环位置（机型分支）

```xml
<Var name="circleTfPosX" const="true" expression="ifelse(#isP2,-1.14,-1.05)"/>
<Var name="circleTfPosY" const="true" expression="ifelse(#isP2,0.514,0.478)"/>
<GLCommand name="circleTf" target="glView" command="setLocalPosition" params="#circleTfPosX,#circleTfPosY,0"/>
```

### 1.6 关键常量

```xml
<Var name="rect_off_init" const="true" expression="0.16" type="number"/>
<Var name="rect_off_aod" const="true" expression="0.12" type="number"/>
<Var name="circle_off_init" const="true" expression="0.22" type="number"/>
<Var name="circle_off_aod" const="true" expression="0.15" type="number"/>
<Var name="circle_thickness_init" const="true" expression="0.04" type="number"/>
<Var name="circle_thickness_aod" const="true" expression="0" type="number"/>
```

## 二、药丸描边 2D 方案（电池信息类）

这份「电池信息」的"药丸描边"是 **2D 形状拼接方案**，不是 GL shader 圆环。

### 2.1 外轮廓描边（药丸底框）

用一个高圆角 `Rectangle` 直接画描边框：

```xml
<Rectangle x="0" y="0" w="285" h="580" fillColor="#00000000" strokeColor="#2E4E63"
           weight="8" cap="round" strokeAlign="center" cornerRadius="142,142" alpha="153"/>
```

关键参数：
- `fillColor="#00000000"` → 透明填充
- `strokeColor` → 描边颜色
- `weight` → 描边粗细
- `cornerRadius="142,142"` → 高圆角（半圆头）
- `strokeAlign="center"` → 描边居中

### 2.2 进度描边（电量填充）

用 `Arc + Line + Arc + Line + Arc` 拼成沿药丸边缘走线的路径：

- 每段用 `visibility` 控制开启时机
- `sweep/min/max` 控制长度
- 总进度统一由 `mBatPathT` 驱动

### 2.3 核心进度变量

```xml
<Var name="mBatCapPerim" expression="1484" type="number"/>  <!-- 总路径长度 -->
<Var name="mBatPathT" expression="max(0,min(#mBatCapPerim,#mBatCapPerim*#batteryLevel*#m5641bab2[2]/100))" type="number"/>
```

### 2.4 圆角参考值

```xml
cornerRadius="28,28"   <!-- 主卡片圆角 -->
cornerRadius="64,64"   <!-- 顶部时间胶囊圆角 -->
```

## 三、两种方案对比

| 特性 | GL 圆环（深渊） | 2D 药丸（电池信息） |
|------|:--:|:--:|
| 实现方式 | GL shader + 材质厚度 | Rectangle + Arc/Line 拼接 |
| 多层描边 | instanceOffsets 9 组 | 手动拼接多段 |
| 姿态跟随 | CameraVectorRotation | 不支持 |
| AOD 隐藏 | uThickness=0 | visibility 控制 |
| 适用场景 | 锁屏/背屏 GL 主题 | 纯 2D 小组件 |
