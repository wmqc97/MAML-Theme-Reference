## 一、日程信息获取（ContentProviderBinder）

### 1.1 数据源

```text
content://com.miui.calendar/transparentevents
```

查询条件：

```text
dtstart < 明天0点 AND dtend >= 当前时间 AND hasExtendedProperties = 0 AND deleted != 1
```

只取当前仍有效、未删除、且不是特殊扩展事件的日程。

### 1.2 查询字段

`_id`、`title`、`dtstart`、`dtend`、`allDay`

### 1.3 核心 binder 片段

```xml
<ContentProviderBinder name="schedule_uri"
    uriExp="'content://com.miui.calendar/transparentevents'"
    whereFormat="dtstart<'%s' AND dtend>='%d' AND hasExtendedProperties=0 AND deleted!=1"
    whereParas="((((#time_sys - (#hour24 * 3600000)) - (#minute * 60000)) - (#second * 1000)) + (((24 * 60) * 60) * 1000)),#time_sys"
    order="allDay ASC,dtstart ASC,dtend ASC"
    columns="_id,title,dtstart,dtend,allDay"
    countName="has_schedule_uri">
    <Variable name="schedule_id_list" column="_id" type="string[]"/>
    <Variable name="schedule_title_list" column="title" type="string[]"/>
    <Variable name="schedule_start_list" column="dtstart" type="string[]"/>
    <Variable name="schedule_end_list" column="dtend" type="string[]"/>
    <Variable name="schedule_all_day_list" column="allDay" type="string[]"/>
    <Trigger>
        <VariableCommand name="schedule_title" expression="ifelse(#has_schedule_uri,ifelse((! strIsEmpty(@schedule_title_list[0])),@schedule_title_list[0],@no_schedule_title),'')" type="string"/>
        <VariableCommand name="schedule_id" expression="ifelse(#has_schedule_uri,@schedule_id_list[0],'')" type="string"/>
        <VariableCommand name="schedule_start" expression="ifelse(#has_schedule_uri,ifelse((@schedule_all_day_list[0] || (num(@schedule_start_list[0]) {= #midnight)),'00:00',@schedule_start_list[0]),'')" type="string"/>
        <VariableCommand name="schedule_end" expression="ifelse(#has_schedule_uri,ifelse((@schedule_all_day_list[0] || (num(@schedule_end_list[0]) }= #tonight)),'24:00',@schedule_end_list[0]),'')" type="string"/>
        <VariableCommand name="has_schedule" expression="ifelse(((((! strIsEmpty(@schedule_title)) ** (! strIsEmpty(@schedule_id))) ** (! strIsEmpty(@schedule_start))) ** (! strIsEmpty(@schedule_end))),1,0)" type="number"/>
    </Trigger>
</ContentProviderBinder>
```

### 1.4 时间修正

- 全天事件或开始时间早于当天零点时 → 开始时间显示为 `00:00`
- 全天事件或结束时间晚于当天夜晚边界时 → 结束时间显示为 `24:00`

### 1.5 可复用的日程变量

```
has_schedule_uri
schedule_id_list / schedule_title_list / schedule_start_list / schedule_end_list / schedule_all_day_list
schedule_id / schedule_title / schedule_start / schedule_end
has_schedule / agree_with_cta / has_festival
```

## 二、电池信息获取（BroadcastBinder + ContentProviderBinder）

### 2.1 电池广播

```xml
<BroadcastBinder action="android.intent.action.BATTERY_CHANGED">
    <Variable name="batteryLevel" type="int" extra="level"/>
    <Variable name="batteryPlugType" type="int" extra="plugged"/>
    <Variable name="batteryTemp" type="int" extra="temperature"/>
    <Variable name="batteryVolt" type="int" extra="voltage"/>
    <Variable name="batteryTech" type="string" extra="technology"/>
    <Variable name="batteryHealth" type="int" extra="health"/>
</BroadcastBinder>
```

### 2.2 设备信息

```text
content://com.miui.personalassistant.deviceinfo
```

```xml
<ContentProviderBinder name="getDeviceInfo" uri="content://com.miui.personalassistant.deviceinfo" countName="hasdeviceinfo">
    <Variable name="device_title" type="string" column="title"/>
    <Variable name="device_phoneModel" type="string" column="phoneModel"/>
    <Variable name="device_screenSize" type="string" column="screenSize"/>
    <Variable name="device_ram" type="string" column="ram"/>
    <Variable name="device_cpu" type="string" column="cpu"/>
    <Variable name="device_batteryCapacity" type="string" column="batteryCapacity"/>
    <Variable name="device_resolution" type="string" column="resolution"/>
</ContentProviderBinder>
```

### 2.3 电量详情

```text
content://com.miui.securitycenter.widgetProvider/getPowerData
```

```xml
<ContentProviderBinder name="getPowerData"
    uri="content://com.miui.securitycenter.widgetProvider/getPowerData"
    columns="leftChargeTime,enduranceTime,powerSaveModeStatus,quickChargeStatus,chargestate"
    countName="hasGetPowerData">
    <Variable name="_leftChargeTime" type="long" column="leftChargeTime"/>
    <Variable name="_enduranceTime" type="long" column="enduranceTime"/>
    <Variable name="_quickChargeStatus" type="int" column="quickChargeStatus"/>
    <Variable name="_chargestate" type="int" column="chargestate"/>
    <Variable name="_powerSaveModeStatus" type="int" column="powerSaveModeStatus"/>
</ContentProviderBinder>
```

### 2.4 电池健康度映射

| `batteryHealth` | 文案 |
|:--:|------|
| `2` | 良好 |
| `3` | 过热 |
| `4` | 没电 |
| `5` | 电量低 |
| `6` | 过电压 |
| `7` | 未知错误 |
| 其他 | 未知 |

### 2.5 充电时长和续航

主题把毫秒值转成 `HH:mm` 文本：
- `_enduranceTime` → 续航时长
- `_leftChargeTime` → 剩余充电时间

### 2.6 最值得直接复用的变量

```
batteryLevel / batteryPlugType / batteryTemp / batteryVolt / batteryTech / batteryHealth
batteryMaxCharging / batteryMaxChargingVolt / batteryChargeCounter
_leftChargeTime / _enduranceTime / _quickChargeStatus / _chargestate / _powerSaveModeStatus
next_alarm_time_long
```

### 2.7 额外广播

```text
miui.intent.action.ACTION_SOC_DECIMAL
```
用于更细粒度充电状态：
- `miui.intent.extra.soc_decimal`
- `miui.intent.extra.soc_decimal_rate`
