## 一、主题包结构（zip）

MAML 主题本质是一个 zip 包，典型结构：

```
主题名.zip
├── description.xml          ★ MIUI 官方标准元数据（名称/作者/版本/描述）
├── manifest.xml             ★ 主题主文件（必需）
├── var_config.xml           可选（仅保留 OnOff/Spinner 等可配置变量）
├── effect.png               可选（预览图）
├── strings/
│   └── strings_zh_CN.xml    可选（字符串资源）
├── spec.js                  权限版（UriRoute 数据脚本）
└── uriroute.json            权限版（UriRoute 注册文件）
```

打包注意：Android 无 `zip` 命令，用 `/data/local/tmp/build_zip.sh <输出.zip> <文件1> <文件2>...`（存储模式）。
文件行尾常为 CRLF，grep 前先 `tr -d '\r'`。

### 各文件职责

| 文件 | 必需 | 职责 |
|------|:--:|------|
| `description.xml` | ✅ | MIUI 官方标准元数据（name/author/version/description），**不再写入 var_config** |
| `manifest.xml` | ✅ | 定义全部变量、函数、UI 元素、数据绑定、生命周期 |
| `var_config.xml` | ❌ | 仅保留 OnOff/Spinner/Slider 等可配置变量，**不承载主题信息** |
| `effect.png` | ❌ | 主题设置列表中的预览缩略图 |
| `strings/strings_zh_CN.xml` | ❌ | 多语言字符串 `<string name="key">值</string>` |
| `spec.js + uriroute.json` | ❌ | 权限版专用，UriRoute 数据脚本 |

## 二、Widget 根标签

```xml
<Widget version="2" frameRate="0" screenWidth="1080"
        useVariableUpdater="Battery,DateTime.Minute"
        scaleByDensity="false">
```

| 属性 | 说明 | 推荐值 |
|------|------|--------|
| `version` | MAML 版本 | `"2"` |
| `frameRate` | 帧率，0=动态省电 | `"0"` |
| `screenWidth` | 设计基准宽 | `"1080"` |
| `useVariableUpdater` | 自动刷新触发 | `"Battery,DateTime.Minute"` |
| `scaleByDensity` | 密度缩放 | `"false"` |
| `useHardwareCanvas` | 硬件加速(MIUI13+) | `"true"` |

### useVariableUpdater 可选值
`Battery` / `DateTime.Day` / `DateTime.Hour` / `DateTime.Minute` / `DateTime.Second`
可组合：`"Battery,DateTime.Minute"`

## 三、manifest.xml 核心结构

```xml
<Widget frameRate="0" scaleByDensity="false" screenWidth="1080" version="2"
        useVariableUpdater="Battery,DateTime.Second">
  <!-- 变量定义 -->
  <Var name="xxx" type="number" expression="..."/>
  <!-- 函数 -->
  <Function name="funcName">...</Function>
  <!-- UI 元素 -->
  <Rectangle .../> <Text .../> <Arc .../> <Line .../> <Group .../>
  <!-- 数据绑定 -->
  <VariableBinders>...</VariableBinders>
  <!-- 生命周期事件 -->
  <ExternalCommands>...</ExternalCommands>
</Widget>
```

## 四、变量系统

### 变量引用前缀

| 前缀 | 类型 | 示例 |
|------|------|------|
| `#var` | 数字 | `#batteryLevel` |
| `@var` | 字符串 | `@customTitle` |
| `$var` | JSON 对象 | `jsonGetString($resultData,'key')` |

### 变量定义

```xml
<!-- 计算变量：每帧按表达式求值 -->
<Var name="scale" type="number" expression="(#view_width / 336)"/>

<!-- 常量（不可变） -->
<Var name="font_path" type="string" expression="'/system/fonts/MiSansVF.ttf'" const="true"/>

<!-- 可变变量：由事件/命令设置，绝不能写 expression！ -->
<Var name="aodState" type="number"/>
```

### ⚠️ 关键机制
- 带 `expression` 的变量：`VariableElement.update()` **每帧 tick 重新求值，覆盖外部写入**
- 需要被 `VariableCommand` 修改的变量：**禁止写 `expression`**
- 动画驱动变量：`expression="0"` + `<VariableAnimation>` 子节点（动画接管）

## 五、运算符与内置函数

### 运算符

| 符号 | 含义 |
|------|------|
| `}` | 大于（`#a } 0` = `>0`） |
| `{` | 小于（`#a { 0` = `<0`） |
| `==` | 等于 |
| `!=` | 不等于 |
| `**` | 逻辑与（布尔乘法） |
| `* / + - %` | 常规算术 |

### 逻辑函数
`ifelse(条件,值1, 条件2,值2, ... 默认值)` — 2n+1 参数，支持多条件

```xml
<!-- 多条件 ifelse -->
<Var name="gradeIndex" expression="ifelse(gt(#batteryLevel,80),1,
                                    gt(#batteryLevel,60),2,
                                    gt(#batteryLevel,40),3,
                                    gt(#batteryLevel,20),4, 5)"/>
```

### 字符串函数
`eqs(@a,'value')` `len(@s)` `substr(@s, start, len)` `eval(@s)` `strIsEmpty(@s)`

### 数学函数
`abs(x)` `int(x)` `num(@s)` `max(a,b)` `min(a,b)` `pow(x,y)` `sqrt(x)`
`sin/cos/tan(x)` `round(x)` `floor(x)` `ceil(x)` `rand(min,max)` `gt/ge/lt/le/eq/ne`

### JSON 函数（权限版）
`newJsonObject()` `strToJson(@s)` `jsonGetString($obj,'key')` `jsonGetInt($obj,'key')`

## 六、系统变量速查

### 屏幕
`#view_width` `#view_height` `#screen_width` `#screen_height`

### 时间
`#time`(ms) `#time_sys` `#year` `#month`(0~11) `#month1`(1~12) `#date`
`#day_of_week-1`(0=日) `#hour12` `#hour24` `#minute` `#second` `#ampm`(0=上午)

### 充电
`#battery_level`(1~100) `#battery_state`(0=正常/1=充电/2=低电/3=充满)
`#ChargeSpeed`(0=普通/1=快充/2=超级快充/3=极速秒充)
`#ChargeWireState`(11=有线/10=无线/-1=未充)

### AOD/深色模式
`#__darkmode`(0/1) `#__darkmode_wallpaper`(0/1)
`aod_desk_state`(系统变量，字符串"1"=AOD，"0"=亮屏，**不被覆盖**)
`preview_mode`(1=预览/0=息屏)

### 触摸
`#touch_x` `#touch_y` `#touch_begin_x` `#touch_begin_y` `#touch_begin_time`

### 音乐
`@musicName.title` `@musicName.artist` `@musicName.album`
`#musicName.music_state`(0=暂停/1=播放) `#musicName.music_position`

### 其他
`#sms_unread_count` `#call_missed_count` `@next_alarm_time` `#volume_level`
`@__miui_version_code`(6=MIUI9/8=MIUI10/9=MIUI11/10=MIUI12)
