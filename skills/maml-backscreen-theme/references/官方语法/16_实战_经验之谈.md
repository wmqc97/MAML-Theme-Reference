## 无障碍模式适配

在标签上添加 `contentDescription` 或 `contentDescriptionExp` 属性添加无障碍播报内容：

```xml
<!-- @talkback_strength_duration 为多语言配置中的内容，eval 函数按需使用 -->
<Button x="100" y="100" w="300" h="80"
    contentDescriptionExp="eval(@talkback_strength_duration)"/>
```

`DateTime` 标签（其他标签不支持）支持 `contentDescriptionFormat` 或 `contentDescriptionFormatExp` 属性来格式化时间（日期）的播报。

## 动态帧率

### 动画场景

通过动态帧率机制可以有效降低小部件的帧率，减少不必要的渲染，从而降低功耗。

策略：将小部件的默认帧率设置为0，在需要做动画或刷新数据时把帧率调高，待动画完成时再将帧率设置为零。

```xml
<!-- 声明一个动画，动画结束后将帧率设置为0 -->
<Var name="ani">
    <VariableAnimation loop="false" initPause="true">
        <AniFrame value="0" time="0" easeType="SineEaseOut"/>
        <AniFrame value="1" time="400"/>
        <Triggers>
            <Trigger action="end">
                <FrameRateCommand rate="0" />
            </Trigger>
        </Triggers>
    </VariableAnimation>
</Var>

<!-- 播放动画前先提高帧率 -->
<Function name="setColor">
    <FrameRateCommand rate="120" />
    <AnimationCommand target="ani" command="play" />
</Function>
```

> 注意：如果有多个动画需要同时触发，但每个动画时长不一样，应将 `<FrameRateCommand rate="0" />` 放到耗时最长的那个动画中，或自行维护一个动画栈，判断所有动画均已停止时才将帧率设置为0。

### 定时刷新场景

通过在根标签添加 `useVariableUpdater` 属性触发小部件自动刷新：

```xml
<Widget version="2" screenWidth="1080" frameRate="0" useVariableUpdater="DateTime.Minute">
    ...
</Widget>
```

`useVariableUpdater` 可选值：

| 值 | 说明 |
|----|------|
| `Battery` | 电池状态发生变化时触发 |
| `DateTime.Day` | 每天触发一次 |
| `DateTime.Hour` | 每小时触发一次 |
| `DateTime.Minute` | 每分钟触发一次 |
| `DateTime.Second` | 每秒触发一次 |

可组合使用，如 `useVariableUpdater="Battery,DateTime.Minute"`。请合理设置以节省系统资源降低功耗。

## 颜色动画

通过将颜色值（16进制整数）绑定到动画变量来实现颜色渐变动画：

```xml
<Var name="colorAni">
    <VariableAnimation loop="false" initPause="true">
        <AniFrame value="0xFF0000FF" time="0"/>
        <AniFrame value="0xFFFF0000" time="500"/>
    </VariableAnimation>
</Var>
<Rectangle x="0" y="0" w="200" h="200" fillColor="#colorAni"/>
```

## 绘制倒影并添加遮罩

```xml
<?xml version="1.0" encoding="utf-8"?>
<Widget version="2" screenWidth="1208" useVariableUpdater="DateTime.Second"
    frameRate="120" resDensity="520">
    <!-- 虚拟屏幕，用于捕获内容 -->
    <VirtualScreen name="v_img" w="#view_width" h="300">
        <Text x="100" y="100" color="#FF00FF" size="100" textExp="'Hello'"/>
    </VirtualScreen>
    <!-- 正常显示内容 -->
    <Image src="v_img" useVirtualScreen="true"/>
    <!-- 倒影 + 渐变遮罩 -->
    <Group layered="true">
        <!-- 倒影：翻转 + 模糊 + 半透明 -->
        <Image src="v_img" useVirtualScreen="true" blur="20" rotationX="180" centerY="300" alpha="100"/>
        <!-- 渐变遮罩 -->
        <Rectangle x="0" y="300" w="#view_width" h="300" xfermode="dst_over">
            <FillShaders>
                <LinearGradient x="0" y="0" x1="0" y1="300" tile="clamp">
                    <GradientStop color="#000000" position="0"/>
                    <GradientStop color="#00000000" position="1"/>
                </LinearGradient>
            </FillShaders>
        </Rectangle>
    </Group>
</Widget>
```

## 通过反射实现特殊操作

### 获取 APK 包版本并判断是否需要更新

```xml
<!-- 你的 app 包名，这里是米家 -->
<Var name="PACKAGE_NAME" expression="'com.xiaomi.smarthome'" type="string"/>
<Function name="validatePackageVersion">
    <FieldCommand targetType="var" target="__objContext"
        class="com.miui.maml.ScreenContext"
        return="thisContext" field="mContext" returnType="object" method="get"/>
    <MethodCommand targetType="var" target="thisContext"
        class="android.content.Context"
        method="getPackageManager" returnType="object" return="packageManage" />
    <MethodCommand targetType="var" target="packageManage"
        class="android.content.pm.PackageManager"
        method="getPackageInfo" paramTypes="String,int"
        params="@PACKAGE_NAME,'0'" returnType="object" return="packageInfo" />
    <!-- packageVersion 是你 app 的版本号（longVersion） -->
    <MethodCommand targetType="var" target="packageInfo"
        class="android.content.pm.PackageInfo"
        return="packageVersion" returnType="int" method="getLongVersionCode"/>
    <VariableCommand name="isAppNeedUpdate"
        expression="ifelse(#isMijiaInstall,ifelse(#packageVersion}80000,0,1),0)"
        type="number"/>
</Function>
```

### 反射转 String 写法

当 MethodCommand 反射方法调用中 params 是 Object 类型导致无法调用时，可用反射进行强制转换：

```xml
<VariableCommand name="picPath" expression="jsonGetString($tmpLayerJson,'path')" type="string"/>
<MethodCommand targetType="ctor" class="java.lang.String"
    return="picPathStrObj" params="@picPath"
    paramTypes="java.lang.String" returnType="object"/>
<MethodCommand targetType="var" target="picCacheMap"
    class="java.util.HashMap" method="get"
    paramTypes="java.lang.Object" params="'picPathStrObj'"
    return="picBitmapCache" returnType="object"/>
```

## 小部件跳转微信小程序

外部打开微信小程序需要继承微信的 SDK，小部件无法直接跳转。目前浏览器集成了微信 SDK，可以通过浏览器支持：maml → 浏览器 → 微信小程序。

```xml
<IntentCommand action="android.intent.action.VIEW"
    uriExp="'https://static.assistant.miui.com/widget/tongcheng_travel/index.html?link='+@marketJumpH5" />
```

优点：
- 用户有微信可跳微信小程序，没有微信支持直接访问兜底 H5 页面
- 若有多个跳转链接，可通过动态配置来实现

缺点：
- 跳转链接结构包括 wechat_program_id 变量，除了拿到小程序跳转 page 页，还需要拿到该微信小程序开发者的原始 Id
- 会增加一步浏览器的跳转，用户体验较差，使用该方案时需要和产品进行沟通
