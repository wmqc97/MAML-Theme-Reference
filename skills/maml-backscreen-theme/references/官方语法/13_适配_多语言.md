# 多语言适配

> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-i18n.html

小部件的多语言适配通过添加 `strings_XXX.xml` 文件来适配多国语言。

---

## 多语言文件命名规则

| 文件名 | 语言 |
|--------|------|
| `strings_zh_CN.xml` | 简体中文 |
| `strings_zh_TW.xml` | 繁体中文（台湾） |
| `strings_zh_HK.xml` | 繁体中文（香港） |
| `strings_en_US.xml` | 英语（美国） |
| `strings_en_GB.xml` | 英语（英国） |
| `strings_ug_CN.xml` | 维吾尔语 |
| `strings_ar.xml` | 阿拉伯语 |

---

## 多语言文件格式

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <string name="RTL">0</string>
    <string name="kcal">KCAL</string>
    <string name="step_unit">步</string>
</resources>
```

在 `manifest.xml` 中通过 `@变量名` 引用多语言字符串：

```xml
<Text x="100" y="100" color="#ffffff" size="50" textExp="@step_unit"/>
```

---

## RTL 适配（维语/阿拉伯语）

维语或阿拉伯语等需要适配 RTL（从右到左）的语言，可在多语言配置中声明一个 RTL 的 string：
- 普通语言（中文、英文等）赋值为 `0`
- 维语或阿拉伯语赋值为 `1`

中文配置 `strings_zh_CN.xml`：

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <string name="RTL">0</string>
    <string name="kcal">KCAL</string>
    <string name="step_unit">步</string>
</resources>
```

维语配置 `strings_ug_CN.xml`：

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <string name="RTL">1</string>
    <string name="kcal">KCAL</string>
    <string name="step">قۇدۇق</string>
</resources>
```

在 `manifest.xml` 中判断 RTL 值来切换 UI 布局：

```xml
<!-- 非 RTL 布局 -->
<Group visibility="!eqs(@RTL,'1')">
    <!-- 非 RTL 内容 -->
</Group>

<!-- RTL 布局 -->
<Group visibility="eqs(@RTL,'1')">
    <!-- RTL 内容（镜像布局） -->
</Group>
```
