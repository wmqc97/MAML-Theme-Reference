> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-data.html

## Broadcast 广播

### 订阅广播

```xml
<VariableBinders>
    <BroadcastBinder action="BROADCAST_ACTION_NAME">
        <!-- 接收广播数据，绑定到 getValueName 变量，sendValueName 为广播发送的数据名 -->
        <Variable name="getValueName" type="number" extra="sendValueName" />
        <Trigger>
            <!-- 接收到广播后的回调，可添加对应命令 -->
        </Trigger>
    </BroadcastBinder>
</VariableBinders>
<Text x="500" y="360" color="#ff00ff" size="50" textExp="#getValueName" />
```

### 发送广播

```xml
<Button x="0" y="0" w="#view_width" h="#view_height">
    <Triggers>
        <Trigger action="up">
            <!-- 不带参数发送广播 -->
            <IntentCommand action="BROADCAST_ACTION_NAME" broadcast="true"/>

            <!-- 带参数发送广播，可同时添加多条 Extra -->
            <IntentCommand action="BROADCAST_ACTION_NAME" broadcast="true">
                <Extra name="sendValueName" type="number" expression="1000" />
            </IntentCommand>

            <!-- 通过包名指定接收方 -->
            <IntentCommand action="BROADCAST_ACTION_NAME" broadcast="true" package="com.miui.home">
                <Extra name="sendValueName" type="number" expression="1000" />
            </IntentCommand>
        </Trigger>
    </Triggers>
</Button>
```

### 常用系统广播

| 广播 | 释义 |
|------|------|
| `android.intent.action.TIME_TICK` | 当前时间改变，每分钟发送 |
| `android.intent.action.TIME_CHANGED` | 时间被设置 |
| `android.intent.action.TIMEZONE_CHANGED` | 时区改变 |
| `android.intent.action.BOOT_COMPLETED` | 系统完成启动 |
| `android.intent.action.PACKAGE_ADDED` | 新应用安装 |
| `android.intent.action.PACKAGE_REMOVED` | 应用被移除 |
| `android.intent.action.BATTERY_CHANGED` | 电池充电状态/电量改变 |
| `android.intent.action.CONFIGURATION_CHANGED` | 设备配置信息改变（含深浅色切换） |
| `android.intent.action.SCREEN_OFF` | 屏幕关闭 |
| `android.intent.action.SCREEN_ON` | 屏幕打开 |

## Provide 数据（ContentProvider）

maml 可以通过安卓的 ContentProvider 跨进程从其他应用获取数据。

### ContentProvider 接口

```xml
<VariableBinders>
    <ContentProviderBinder name="weather"
        columns="temperature,description"
        countName="hasWeather"
        dependency="selected_city"
        uri="content://weather/actualWeatherData/1">
        <Variable name="weather_temperature" type="number" column="temperature" />
        <Variable name="weather_description" type="number" column="description" />
    </ContentProviderBinder>
</VariableBinders>
```

> 使用 `countName` 定义的变量（如 `#hasWeather`）判断是否获取到数据：为0时未获取到，否则已获取。

> 注意：Variable 只能获取 string[]，如果要获取 number[]，需要先获取 string[] 再通过 `num(xxx)` 转换。

### JSON 数据解析

```xml
<VariableBinders>
    <ContentProviderBinder name="a" uri="content://xxxx" columns="XXX" countName="hasData">
        <Variable name="str" type="string" column="XXX"/>
        <Trigger>
            <!-- 将 JSON 字符串解析为 jsonO 对象，绑定到 data 变量 -->
            <VariableCommand name="data" expression="strToJson(@str)" type="jsonO"/>
        </Trigger>
    </ContentProviderBinder>
</VariableBinders>
```

### 通过 ContentProvider 获取 Bitmap

```xml
<VariableBinders>
    <ContentProviderBinder name="noti"
        uri="content://keyguard.notification/notifications"
        columns="icon,title,content,time,info,subtext,key"
        countName="hasnotifications">
        <Variable name="notification_icon" type="blob.bitmap" column="icon" row="0"/>
        <Variable name="notification_title" type="string" column="title" row="0"/>
    </ContentProviderBinder>
</VariableBinders>
<Text x="100" y="40" color="#000000" size="42" textExp="@notification_title_1"/>
<!-- 通过 name 绑定 notification_icon 这个 bitmap -->
<Image name="notification_icon" x="100" y="100" w="150" h="150" alignV="center"/>
```

### 刷新数据

provide 默认在 init 时刷新数据，如需动态刷新：

```xml
<Trigger>
    <BinderCommand name="weather" command="refresh" />
</Trigger>
```

实现每分钟自动刷新天气数据：

```xml
<VariableBinders>
    <ContentProviderBinder name="weather" columns="temperature,description"
        countName="hasWeather" dependency="selected_city"
        uri="content://weather/actualWeatherData/1">
        <Variable name="weather_temperature" type="number" column="temperature" />
        <Variable name="weather_description" type="number" column="description" />
    </ContentProviderBinder>
    <!-- 每分钟刷新一下数据 -->
    <BroadcastBinder action="android.intent.action.TIME_TICK">
        <Trigger>
            <BinderCommand name="weather" command="refresh" />
        </Trigger>
    </BroadcastBinder>
</VariableBinders>
```

> 注意：ContentProviderBinder 与 BroadcastBinder 都是 Binder 的一种，多种类型可同时使用，但不能相互嵌套，且必须包在全局唯一的 `VariableBinders` 标签内。其他还有 `SensorBinder`、`SettingsBinder`、`FileBinder` 等。
