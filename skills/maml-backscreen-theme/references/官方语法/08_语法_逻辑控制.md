# 逻辑控制

> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-logic.html

---

## 条件控制（condition 属性）

所有命令都可以通过 `condition` 属性进行条件控制：

```xml
<Trigger>
    <!-- 只有当 num <= 20 时才执行 -->
    <VariableCommand name="num" expression="#num+1" condition="#num{=20"/>
</Trigger>
```

条件表达式支持：`#` 开头的变量、`=` 比较运算符、`{`/`}` 判断运算符、`**` 逻辑与、`||` 逻辑或。

---

## IF 语句（IfCommand）

类似高级语言的 if-else，`ifCondition` 为 true 时执行 `Consequent`，否则执行 `Alternate`。不支持 else-if，需要嵌套使用。

```xml
<IfCommand ifCondition="#a==1">
    <!-- 满足 ifCondition 时执行 -->
    <Consequent>
        <VariableCommand name="result" expression="'条件为真'" type="string"/>
        <AnimationCommand target="ani" command="play"/>
    </Consequent>

    <!-- 不满足 ifCondition 时执行 -->
    <Alternate>
        <VariableCommand name="result" expression="'条件为假'" type="string"/>
    </Alternate>
</IfCommand>
```

IfCommand 也是 Command 的一种，需要放在 Trigger 回调里。

---

## 循环语句（LoopCommand）

类似高级语言的 for 循环，支持 `loopCondition`：

```xml
<Trigger>
    <!-- begin 到 end 循环，满足 loopCondition 才执行 -->
    <LoopCommand begin="0" end="99" indexName="i" loopCondition="#i{50">
        <VariableCommand name="loopCount" expression="#i"/>
    </LoopCommand>
</Trigger>
```

简化写法（index 默认从0开始，count 默认是1）：

```xml
<Trigger>
    <LoopCommand count="100" indexName="i">
        <!-- 修改一个外面已经声明好长度的数组 -->
        <VariableCommand name="arr" type="number[]" index="#i" expression="#i"/>
    </LoopCommand>
</Trigger>
```

LoopCommand 也是 Command 的一种，需要放在 Trigger 回调里。

---

## 命令集（MultiCommand）

把满足同一执行条件的命令放到一个 MultiCommand 里，通常配合 `condition` 属性使用，体验上类似 switch 语句：

```xml
<Trigger>
    <MultiCommand condition="#a==0">
        <VariableCommand name="a" expression="'foo'" type="string"/>
        <AnimationCommand target="ani" command="play"/>
    </MultiCommand>
    <MultiCommand condition="#a==1">
        <VariableCommand name="a" expression="'bar'" type="string"/>
        <AnimationCommand target="ani" command="play"/>
    </MultiCommand>
</Trigger>
```

MultiCommand 也是 Command 的一种，需要放在 Trigger 回调里。

---

## 方法（Function）

将一组命令封装到一个方法中，通过 `FunctionCommand` 调用。

注意事项：
- Function **不能传参**
- Function **没有作用域**，操作的是全局状态的数据
- Function **没有返回值**，只包装对应的命令
- Function **不能递归**

```xml
<!-- 定义方法 -->
<Function name="myFun">
    <VariableCommand name="count" expression="#count+1"/>
    <AnimationCommand target="ani" command="play"/>
</Function>

<!-- 调用方法（必须在 Trigger 或 Function 内部） -->
<Trigger action="up">
    <FunctionCommand target="myFun" />
</Trigger>
```
