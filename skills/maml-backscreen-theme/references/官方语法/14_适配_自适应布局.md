# 自适应布局

> 来源：https://maml-widget-guide.jst.xiaomi.net/widget-device.html

maml 画布的大小在不同机型上会不一样，甚至在同一手机的不同桌面布局状态下画布的尺寸也不相同。由于 maml 是基于绝对坐标进行定位，如果通过写死的固定坐标进行布局，有可能会导致部分内容因为画布大小不够而被裁切。

---

## 自适应布局方案

通过获取 `#view_width`、`#view_height` 配合 `align` 和 `alignV` 属性，再通过表达式计算元素相对整个 view 画布大小来进行定位。

```xml
<Widget version="2" screenWidth="1080" frameRate="0">
    <!-- 居中显示的文字 -->
    <Text x="#view_width/2" y="#view_height/2"
        color="#ffffff" size="50"
        textExp="'Hello'"
        align="center"
        alignV="center"/>

    <!-- 右下角的图片 -->
    <Image src="icon.png"
        x="#view_width - 100"
        y="#view_height - 100"
        w="80" h="80"/>

    <!-- 宽度铺满的矩形 -->
    <Rectangle x="0" y="0" w="#view_width" h="10" fillColor="#ff0000"/>
</Widget>
```

---

## 常用自适应技巧

### 水平居中

```xml
<Text x="#view_width/2" y="100" align="center" .../>
```

### 垂直居中

```xml
<Text x="100" y="#view_height/2" alignV="center" .../>
```

### 完全居中

```xml
<Group x="#view_width/2 - 150" y="#view_height/2 - 75">
    <!-- 内部元素基于 Group 原点定位 -->
</Group>
```

### 右对齐

```xml
<Text x="#view_width" y="100" align="right" .../>
```

### 底部对齐

```xml
<Image src="bg.png" x="0" y="#view_height - 200" w="#view_width" h="200"/>
```

---

## 关键全局变量

| 变量 | 说明 |
|------|------|
| `#view_width` | 部件宽度 |
| `#view_height` | 部件高度 |
| `#screen_width` | 屏幕宽度 |
| `#screen_height` | 屏幕高度 |
| `#raw_screen_width` | 物理宽度（不受 screenWidth 影响） |
| `#raw_screen_height` | 物理高度 |
