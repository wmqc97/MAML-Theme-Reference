## 一、黄金 10 条（创建任何 HTML 主题必守）

| # | 规则 | 一句话实现 |
|---|------|-----------|
| 1 | 视口禁缩放 | `<meta name="viewport" content="width=976, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover">` |
| 2 | 全屏+滚动 | `html,body{width:100%;min-height:100%;overflow-x:hidden;overflow-y:auto}` |

| 4 | 内容不出屏 | 字号按可用宽反推（`min(H*0.30, availW/3.5)`）+ 绘制双端夹紧（`x≥SAFE+2`、右端≤W-8）+ measureWorst 实测兜底 |
| 5 | 控件不重叠 | 全部 W/H 比例布局 + 间距；运行时 resize 重算 |
| 6 | 高清 | 双层画布：bg 半 dpr（柔光省电）/ fg 全 dpr（锐利）；精灵×DPR；**drawImage 必须 9 参**（否则×DPR² 爆炸） |
| 7 | 减负防卡 | 位图预渲染；EMA 帧耗时>46ms 自动降 eco（关雨/网格/雷达）；AOD 停 rAF；禁在线资源 |
| 8 | AOD 不冻结 | `__setAod(1)` 画一帧静态即停 rAF；setTimeout 精确到整分钟重绘（wvDrawStatic/scheduleAodTick）；**隐藏秒只显 HH:MM** |
| 9 | 作者 | var_config 第一行 Text 只读：`✦ 唯梦倾城 ✦`/item=`Q群 2159063054`；description.xml author/designer 同步 |
| 10 | 手势默认不加 | 仅用户明确要求才加；MiRoot 有导入自动注入，勿重复内置 |

## 二、最小骨架（可直接复制起步）

```html
<meta name="viewport" content="width=976, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover">
<style>
html,body{margin:0;padding:0;width:100%;min-height:100%;overflow-x:hidden;overflow-y:auto;background:#000;user-select:none}
body{padding-left:29vw;box-sizing:border-box}
#bg,#fg{position:fixed;left:0;top:0;width:100%;height:100%;display:block}
</style>
<canvas id="bg"></canvas><canvas id="fg"></canvas>
<script>
/* 核心基调：W/H/DPR/SAFE + 双层画布变换 + sprite(mesh) + drawImage 9参 + __setAod/AOD定时 */
var W=348,H=212,DPR=1,SAFE=104;
function resize(){
  W=innerWidth; H=innerHeight; DPR=Math.min(devicePixelRatio||1,3);
  SAFE=Math.round(W*.30);
  b.setTransform(1,0,0,1,0,0); c.setTransform(1,0,0,1,0,0);
  bg.width=Math.round(W*DPR*.5); bg.height=Math.round(H*DPR*.5);
  fg.width=Math.round(W*DPR);   fg.height=Math.round(H*DPR);
  b.scale(bg.width/W,bg.height/H); c.scale(fg.width/W,fg.height/H);
  buildAll();                      /* 精灵×DPR 预渲染、布局按 W/H 比例 */
}
function setAod(m){var v=(Number(m)===1||m===true||m==='1');if(v===aod)return;aod=v;
  if(aod){wvDrawStatic();scheduleAodTick();stopLoop()}else{clearTimeout(aodTimer);startLoop()}}
function wvDrawStatic(){var t=(performance.now()/1000)%1000;drawBG(t);drawFG(t)}
function scheduleAodTick(){if(!aod)return;var d=new Date();
  var ms=(60-d.getSeconds())*1000-d.getMilliseconds()+50;
  aodTimer=setTimeout(function(){if(aod){wvDrawStatic();scheduleAodTick()}},ms)}
window.__setAod=setAod;
resize();startLoop();
</script>
```

## 三、一条龙流程（每次创建/修改必走）

```
需求 →（缺信息弹 ask_user 问清机型/效果/取舍）→ 按 13 号模板写 4 文件
→ QuickJS `new Function` 全量语法体检（防黑屏）
→ 纯 zip（cd 目录 && zip -r out.zip . -x '*.bak'）
→ theme_probe=rear_widget + maml_validate 通过（WebViewCommand 报未知=正常）
→ test_install（keepBackup + jumpToSettings）→ 用户手动应用 → 翻转验证 → 迭代
⚠️ 改 HTML 一律全量重写+体检，不要 shell 拼接（曾坏档丢函数）
```
