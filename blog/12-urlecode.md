# URLEncode 小工具

> 来源：https://zhuti.designer.xiaomi.com/docs/blog/URLEncode.html

URLEncode 是使用 URL 编码对字符串进行编码处理的函数。

该函数使用 URL 编码对字符串进行编码。例如空格变成加号。主页表单数据传输在发送前使用 urlencode 编码。

URI 有保留字符和非保留字符之分。保留字符有特殊含义（如斜杠用作分隔符），非保留字符没有。百分号编码将保留字符表示为特殊字符序列。

## 转换规则

| 字符 | 编码 |
| ---- | ---- |
| 空格 | %20  |
| !    | %21  |
| #    | %23  |
| $    | %24  |
| %    | %25  |
| +    | %2B  |
| @    | %40  |
| :    | %3A  |
| =    | %3D  |
| ?    | %3F  |
