# 缓动函数速查表

> 来源：https://zhuti.designer.xiaomi.com/docs/blog/easy.html

## 缓动函数动画参数

| 缓动类型         | 详解                            |
| ---------------- | ------------------------------- |
| SineEaseIn       | 缓入 正弦曲线缓动               |
| SineEaseOut      | 缓出 正弦曲线缓动               |
| SineEaseInOut    | 缓入缓出 正弦曲线缓动           |
| CubicEaseIn      | 缓入 三次方缓动                 |
| CubicEaseOut     | 缓出 三次方缓动                 |
| CubicEaseInOut   | 缓入缓出 三次方缓动             |
| QuartEaseIn      | 缓入 四次方缓动                 |
| QuartEaseOut     | 缓出 四次方缓动                 |
| QuartEaseInOut   | 缓入缓出 四次方缓动             |
| QuintEaseIn      | 缓入 五次方缓动                 |
| QuintEaseOut     | 缓出 五次方缓动                 |
| QuintEaseInOut   | 缓入缓出 五次方缓动             |
| ExpoEaseIn       | 缓入 指数曲线缓动               |
| ExpoEaseOut      | 缓出 指数曲线缓动               |
| ExpoEaseInOut    | 缓入缓出 指数曲线缓动           |
| CircEaseIn       | 缓入 圆形曲线缓动               |
| CircEaseOut      | 缓出 圆形曲线缓动               |
| CircEaseInOut    | 缓入缓出 圆形曲线缓动           |
| BackEaseIn       | 缓入 超过范围的三次方缓动       |
| BackEaseOut      | 缓出 超过范围的三次方缓动       |
| BackEaseInOut    | 缓入缓出 超过范围的三次方缓动   |
| ElasticEaseIn    | 缓入 指数衰减的正弦曲线缓动     |
| ElasticEaseOut   | 缓出 指数衰减的正弦曲线缓动     |
| ElasticEaseInOut | 缓入缓出 指数衰减的正弦曲线缓动 |
| BounceEaseIn     | 缓入 指数衰减的反弹缓动         |
| BounceEaseOut    | 缓出 指数衰减的反弹缓动         |
| BounceEaseInOut  | 缓入缓出 指数衰减的反弹缓动     |
